\chapter{Defining probability}

\section{Why probability?}

Observed data are the results of processes whose behavior we may not fully
know. To reason about them, we describe the process with a probabilistic
model. Probability lets us work forward from a model to possible outcomes;
statistical inference uses observed outcomes to learn about the model.

\begin{framedexample}{A coin toss}
Let $\theta=P(\text{heads})$ be the probability that a coin lands heads.
If $\theta$ is known, we can ask how likely it is to observe three heads
in five tosses. If instead we observe three heads in five tosses while
$\theta$ is unknown, we can use those data to learn about $\theta$.
\end{framedexample}

\section{Sample spaces and events}

Before assigning probabilities, we must specify what the experiment can
produce. We start with a finite set of possible results.

\begin{frameddefn}{Outcomes and events}\label{def:outcomes-events}
A random experiment is a process whose result is not known in advance.
Each possible result is an \emph{outcome} $\omega$. The set of all possible
outcomes is the \emph{sample space} $\Omega$. An \emph{event} is a subset
$A\subseteq\Omega$; it occurs when the observed outcome belongs to $A$.
\end{frameddefn}

\begin{framedexample}{Rolling a die}\label{ex:die-events}
For one roll of a six-sided die, the sample space is
$\Omega=\{1,2,3,4,5,6\}$. The event ``the result is even'' is
$A=\{2,4,6\}$. The whole sample space $\Omega$ is the certain event,
while $\varnothing$ is the impossible event.
\end{framedexample}

\subsection{Operations on events}

Events are subsets of the same sample space $\Omega$, so set operations
let us describe new events in terms of $A$ and $B$:

\begin{itemize}
  \item \textbf{Union:}
  $A\cup B:=\{\omega\in\Omega:\omega\in A\text{ or }\omega\in B\}$.
  This event occurs when at least one of $A$ and $B$ occurs;
  ``or'' includes the case in which both occur.
  In particular, $A\cup\varnothing=A$ and $A\cup\Omega=\Omega$.

  \item \textbf{Intersection:}
  $A\cap B:=\{\omega\in\Omega:\omega\in A\text{ and }\omega\in B\}$.
  This event occurs when both $A$ and $B$ occur.
  In particular, $A\cap\Omega=A$ and $A\cap\varnothing=\varnothing$.

  \item \textbf{Complement:}
  $A^c:=\Omega\setminus A
       =\{\omega\in\Omega:\omega\notin A\}$.
  This event occurs when $A$ does not occur.
  In particular, $A\cup A^c=\Omega$ and $A\cap A^c=\varnothing$.
\end{itemize}

For the die in Example~\ref{ex:die-events}, let
$B=\{4,5,6\}$ be the event ``the result is at least four''. Then
$A\cup B=\{2,4,5,6\}$, $A\cap B=\{4,6\}$, and
$A^c=\{1,3,5\}$.

Two events are \emph{disjoint} when $A\cap B=\varnothing$, so they
cannot occur together. If $A\subseteq B$, every outcome in $A$ is
also in $B$: whenever $A$ occurs, $B$ occurs.

\begin{framedprop}{De Morgan's laws}\label{prop:de-morgan}
For any events $A$ and $B$,
\[
  (A\cup B)^c=A^c\cap B^c,
  \qquad
  (A\cap B)^c=A^c\cup B^c.
\]
More generally, for events $A_1,\ldots,A_n$,
\[
  \left(\bigcup_{i=1}^{n}A_i\right)^c
    =\bigcap_{i=1}^{n}A_i^c,
  \qquad
  \left(\bigcap_{i=1}^{n}A_i\right)^c
    =\bigcup_{i=1}^{n}A_i^c.
\]
\end{framedprop}

The first identity says that ``none occurs'' means that every event
fails. The second says that ``not all occur'' means that at least one
event fails. We will use the second identity in the proof of
Bonferroni's inequality.

\subsection{Partitions and event decomposition}

A useful way to study an event is to split it into disjoint pieces. For
any events $A$ and $B$, exactly one of $B$ and $B^c$ occurs, so
\[
  A=A\cap\Omega
   =A\cap(B\cup B^c)
   =(A\cap B)\cup(A\cap B^c).
\]
The two events on the right are disjoint. For example, a car can fail
an emissions test either while it pollutes or while it does not.

More generally, a \emph{partition} $B_1,\ldots,B_n$ of $\Omega$ consists
of pairwise disjoint events whose union is $\Omega$. Every event $A$
can then be written as
\[
  A=\bigcup_{i=1}^{n}(A\cap B_i),
  \qquad
  (A\cap B_i)\cap(A\cap B_j)=\varnothing\quad(i\neq j).
\]
This decomposition will let us add the probabilities of different
ways in which the same event can occur.

\section{Probability}

There are several ways to interpret a probability. Under a
\emph{symmetry} assumption, equally likely outcomes give
$P(A)=|A|/|\Omega|$. A \emph{frequency} interpretation concerns the
long-run proportion of repetitions in which $A$ occurs. A
\emph{subjective} interpretation expresses a degree of belief about
$A$. The axioms below state the mathematical rules that a probability
assignment must satisfy, regardless of its interpretation.

\begin{framedexample}{Two dice}
If the $36$ ordered results of rolling two dice are equally likely,
they form the sample space $\Omega=\{1,\ldots,6\}^2$. The sum is eight for
$(2,6),(3,5),(4,4),(5,3),(6,2)$, so the probability of that event is
$5/36$. Counting outcomes this way is valid because the ordered pairs
are equally likely.
\end{framedexample}

\begin{frameddefn}{Probability on a finite sample space}\label{def:probability-finite}
A probability measure $P$ assigns a number $P(A)$ to every event
$A\subseteq\Omega$ such that:
\begin{enumerate}
  \item $0\leq P(A)\leq 1$ for every event $A$;
  \item $P(\Omega)=1$;
  \item if $A\cap B=\varnothing$, then
        $P(A\cup B)=P(A)+P(B)$.
\end{enumerate}
The last property is called \emph{finite additivity}.
\end{frameddefn}

Because $A$ and $A^c$ are disjoint and their union is $\Omega$,
these axioms give $P(A^c)=1-P(A)$. In particular,
$P(\varnothing)=0$. 

They also imply \emph{monotonicity}: if
$A\subseteq B$, then $B=A\cup(B\cap A^c)$ is a disjoint union,
so $P(B)=P(A)+P(B\cap A^c)\geq P(A)$.

\begin{framedexample}{A fair die}
If the six outcomes of a die roll are equally likely, each has
probability $1/6$. The event $A=\{2,4,6\}$ therefore has probability
$P(A)=3/6=1/2$.
\end{framedexample}

For an infinite sample space, finite additivity is replaced by
\emph{countable additivity}: for pairwise disjoint events
$A_1,A_2,\ldots$,
\[
  P\!\left(\bigcup_{i=1}^{\infty}A_i\right)
    =\sum_{i=1}^{\infty}P(A_i).
\]
In that setting, a probability measure is defined on a suitable
family of events rather than necessarily on every subset of
$\Omega$. On a finite sample space, the finite formulation above is
enough.

\subsection{Inclusion--exclusion}

Finite additivity directly handles disjoint events. If $A$ and $B$
overlap, adding $P(A)$ and $P(B)$ counts their intersection twice.

\begin{framedprop}{Inclusion--exclusion for two events}
For any events $A$ and $B$,
\[
  P(A\cup B)=P(A)+P(B)-P(A\cap B).
\]
\end{framedprop}

\begin{proof}
Split $A\cup B$ into the disjoint events $A$ and $B\cap A^c$:
\[
  P(A\cup B)=P(A)+P(B\cap A^c).
\]
The event $B$ is itself the disjoint union of $A\cap B$ and
$A^c\cap B$. Thus
$P(B\cap A^c)=P(B)-P(A\cap B)$, which gives the formula.
\end{proof}

\begin{framedexample}{Overlapping die events}
Let $A=\{2,4,6\}$ and $B=\{4,5,6\}$. Then
$P(A)=P(B)=1/2$ and $P(A\cap B)=1/3$. Therefore
\[
  P(A\cup B)=\frac12+\frac12-\frac13=\frac23,
\]
in agreement with $A\cup B=\{2,4,5,6\}$.
\end{framedexample}

Applying the two-event formula twice gives the three-event version:
\[
\begin{aligned}
P(A\cup B\cup C)
  ={}&P(A)+P(B)+P(C)\\
    &-P(A\cap B)-P(A\cap C)-P(B\cap C)\\
    &+P(A\cap B\cap C).
\end{aligned}
\]
The final term restores outcomes in all three events: they were
added three times and subtracted three times.

For $n$ events, the same pattern continues:
\[
  P\!\left(\bigcup_{i=1}^{n}A_i\right)
  =\sum_{\varnothing\neq I\subseteq\{1,\ldots,n\}}
     (-1)^{|I|+1}P\!\left(\bigcap_{i\in I}A_i\right).
\]
To see why, consider an outcome contained in exactly $k$ of the
events. It is counted $\binom{k}{j}$ times among the intersections
of size $j$, so its total coefficient on the right is
$\sum_{j=1}^{k}(-1)^{j+1}\binom{k}{j}=1$. An outcome in none of the
events contributes zero to both sides.

\subsection{Probability bounds}

Sometimes the probabilities of intersections are unknown. We can
still bound the probability of a union.

\begin{framedprop}{Union bound (Boole's inequality)}
For events $A_1,\ldots,A_n$,
\[
  P\!\left(\bigcup_{i=1}^{n} A_i\right)
  \leq \sum_{i=1}^{n}P(A_i).
\]
\end{framedprop}

\begin{proof}
We prove the bound by induction on the number of events.

\textbf{Base case ($n=1$).} The union contains only $A_1$, so the
inequality is an equality: $P(A_1)=\sum_{i=1}^{1}P(A_i)$.

\textbf{Inductive step.} Assume the bound holds for $n$ events and set
$U_n=\bigcup_{i=1}^{n}A_i$. The union of $n+1$ events is
$U_n\cup A_{n+1}$. Applying inclusion--exclusion gives
\[
\begin{aligned}
P\!\left(\bigcup_{i=1}^{n+1}A_i\right)
 &=P(U_n)+P(A_{n+1})-P(U_n\cap A_{n+1})\\
 &\leq P(U_n)+P(A_{n+1})\\
 &\leq \sum_{i=1}^{n}P(A_i)+P(A_{n+1})
  =\sum_{i=1}^{n+1}P(A_i).
\end{aligned}
\]
The first inequality uses $P(U_n\cap A_{n+1})\geq0$; the second uses
the induction hypothesis. Thus the bound holds for every $n\geq1$.
\end{proof}

For a countable sequence, the same inequality follows by applying
the finite bound to the first $n$ events and taking the limit.

\begin{framedprop}{Bonferroni's inequality}
For events $A_1,\ldots,A_n$,
\[
  P\!\left(\bigcap_{i=1}^{n} A_i\right)
  \geq \sum_{i=1}^{n}P(A_i)-(n-1).
\]
\end{framedprop}

\begin{proof}
The second $n$-event form of De Morgan's law turns the complement of
an intersection into a union of complements. Then the union bound gives
\[
\begin{aligned}
P\!\left(\bigcap_{i=1}^{n}A_i\right)
 &=1-P\!\left(\bigcup_{i=1}^{n}A_i^c\right)\\
 &\geq1-\sum_{i=1}^{n}P(A_i^c)\\
 &=1-\sum_{i=1}^{n}(1-P(A_i))
  =\sum_{i=1}^{n}P(A_i)-(n-1).
\end{aligned}
\]
\end{proof}

\subsection{Application: a randomized identity test}

Suppose $F$ and $G$ are polynomials of degree at most $d$. We want to
test whether they are identical without comparing all their coefficients.
Choose a nonempty finite set $S$ of possible evaluation points.

\Needspace{12\baselineskip}
\begin{framedalgo}{Randomized polynomial identity test}\label{alg:identity-test}
Given $F$, $G$, and $S$, report whether the polynomials differ or may
be identical.
\begin{algorithmic}
  \Function{IdentityTest}{$F,G,S$}
    \State Draw $R$ uniformly at random from $S$
    \If{$F(R)\neq G(R)$}
      \State \Return \textsc{different}
    \Else
      \State \Return \textsc{possibly equal}
    \EndIf
  \EndFunction
\end{algorithmic}
\end{framedalgo}

If $F=G$, the test never reports a difference. If $F\neq G$, it fails
to detect the difference only when $R$ belongs to the event
\[
  E=\{r\in S:F(r)=G(r)\}.
\]
Indeed, $E$ contains the roots in $S$ of the nonzero polynomial
$H=F-G$, which has at most $d$ roots. Because $R$ is uniform on $S$,
\[
  P(R\in E)=\frac{|E|}{|S|}\leq\frac{d}{|S|}.
\]
For $S=\{1,\ldots,100d\}$ with $d\geq1$, the probability of missing a
difference is at most $1/100$. The possible error is \emph{one-sided}:
``different'' is certain, while ``possibly equal'' is not a proof of
identity.

\subsection{Odds}

For an event $A$ with $P(A)<1$, its \emph{odds in favor} are
\[
  O(A):=\frac{P(A)}{P(A^c)}
      =\frac{P(A)}{1-P(A)}.
\]
Conversely, $P(A)=O(A)/(1+O(A))$. For a fair die, the odds in
favor of rolling a six are $(1/6)/(5/6)=1/5$, often stated as
one to five. This is different from saying that the probability
is $1/5$; the probability is $1/6$.

\section{Independent events}
\begin{frameddefn}{Independent events}
\label{def:independent-events}
Two events $A$ and $B$ are independent if
\[
  P(A\cap B)=P(A)P(B).
\]
\end{frameddefn}
When $P(B)>0$, this is equivalent to $P(A\mid B)=P(A)$:
knowing that $B$ occurred does not change the probability of $A$.

\section{From outcomes to data}

Imagine picking one student at random from a class. Before the draw, we do
not know who we will get; afterwards, we can write down that student's
height, weight, and age. Probability describes the draw, while the numbers
we write down are the data.

The possible outcomes form $\Omega$, and $\omega\in\Omega$ is the outcome
that actually occurs. We write $(\Omega,\mathcal F,P)$ for the probability
space: $\mathcal F$ contains the events to which $P$ assigns probabilities.
For a finite $\Omega$, as in Chapter 1, every subset can be an event.

\begin{tcolorbox}[definitionbox,title={Definition (informal): Random object}]
Given a probability space, a \emph{random object} is a map
\[
  Z:\Omega\longrightarrow\mathcal T,
\]
where $\mathcal T$ is a suitable space of observations for our
data-collection process.
\end{tcolorbox}

\begingroup
\renewcommand{\thefootnote}{\fnsymbol{footnote}}
\footnotetext[1]{A rigorous definition of measurability is beyond the scope of this course.}
\endgroup

\begin{frameddefn}{Random object}\label{def:random-object}
A \emph{random object} is a measurable\begingroup\renewcommand{\thefootnote}{\fnsymbol{footnote}}\footnotemark[1]\endgroup\ map from outcomes to possible
observations:
\[
  Z:\Omega\longrightarrow\mathcal T,
  \qquad \omega\longmapsto Z(\omega).
\]
The set $\mathcal T$ says what kind of thing we record. It could contain
numbers, vectors, images, or text messages. Once $\omega$ is known,
$Z(\omega)$ is the observation we get.
\end{frameddefn}

Think of $Z$ as the rule that turns the outcome into a piece of data.
``Measurable'' is the technical condition that lets us assign a probability
to questions about that data, such as ``is the selected student taller
than $180$ cm?''

\section{Random variables and random vectors}

Often the observation is a number or a list of numbers. These are two
particularly useful kinds of random objects.

\begin{frameddefn}{Random variable}\label{def:random-variable}
A \emph{random variable} is a measurable map
\[
  X:\Omega\longrightarrow\mathbb R.
\]
It assigns one real number $X(\omega)$ to each outcome $\omega$.
\end{frameddefn}

\begin{center}
  \includegraphics[width=0.65\textwidth]{assets/random-variable-map.png}

  {\small A map from $\Omega$ to $\mathbb R$. Illustration from Brutti's slides.}
\end{center}

\begin{frameddefn}{Random vector}\label{def:random-vector}
A \emph{$p$-dimensional random vector} is a measurable map
\[
  \underline{X}:\Omega\longrightarrow\mathbb R^p,
  \qquad
  \underline{X}(\omega)
    :=\bigl(X_1(\omega),\ldots,X_p(\omega)\bigr).
\]
Each coordinate $X_j$ is a real-valued random variable. Thus one
outcome gives us $p$ numbers collected into a vector. These measurements
can be related; they do not have to be independent.
\end{frameddefn}

\begin{notebox}[Notation]
In these notes, we denote a random vector by $\underline{X}$
($X$ with a bar underneath):
\[
  \underline{X}=(X_1,\ldots,X_p).
\]
\end{notebox}


\Needspace{17\baselineskip}
\begin{framedexample}{One student, one number or three}
Pick a student at random and let $\omega$ identify the student selected.
If $H$ records height in centimetres, then $H(\omega)$ is one number.
For a student who is $178$ cm tall, $H(\omega)=178$.

Now record height $H$, weight $W$ in kilograms, and age $A$ in years for
that \emph{same} student:
\[
  \underline{X}(\omega)
    =\begin{pmatrix}H(\omega)\\W(\omega)\\A(\omega)\end{pmatrix}
    =\begin{pmatrix}178\\72\\21\end{pmatrix}\in\mathbb R^3.
\]
The draw gives us one student, not three. We simply take three
measurements of that student. Before the draw, $H$ and $\underline{X}$ are
uncertain; for the selected student, their values are fixed.
\end{framedexample}

In supervised learning, each sampled item gives us an input $\underline{X}$
(the features) and a target $Y$ (the label or quantity of interest).
Before we see the item, both are uncertain; for an observed item, their
values are fixed.

\begin{framedexample}{House prices}
Choose a house at random. Use its floor area in square metres, number of
rooms, and age in years as features. For a particular house with $85$ m$^2$,
$3$ rooms, and an age of $10$ years, the data look like this:
\[
  \underline{X}(\omega)=(85,3,10),
  \qquad Y(\omega)=240{,}000\ \text{euros}.
\]
The three features make a random vector; the sale price is one random
variable.
\end{framedexample}

\begin{framedexample}{Image labels}
Take a randomly chosen $64\times64$ grayscale photo. Each pixel is one
number from $0$ (black) to $255$ (white). Putting the pixels in a fixed
order gives $\underline{X}(\omega)\in\mathbb R^{4096}$: one vector with
$4096$ entries for one photo. If we set $Y(\omega)=1$ for a cat and
$Y(\omega)=0$ for a dog, then a cat photo gives one feature vector and
the single label $1$. The pixels can be related even though they are
separate coordinates of $\underline{X}$.
\end{framedexample}

\section{Preimages and induced probabilities}

To ask a probability question about the values of $X$, we first find
the outcomes that produce those values.

\begin{frameddefn}{Preimage}\label{def:preimage}
For a random variable $X:\Omega\to\mathbb R$ and a set
$E\subseteq\mathbb R$, the \emph{preimage} (or \emph{inverse image}) of
$E$ is
\[
  X^{-1}(E):=\{\omega\in\Omega:X(\omega)\in E\}\subseteq\Omega.
\]
To find this event, we collect the outcomes whose outputs fall in $E$.
Whenever $X^{-1}(E)$ is an event, we define
\[
  \begin{aligned}
    P(X\in E)&:=P\bigl(X^{-1}(E)\bigr)\\
              &=P\bigl(\{\omega\in\Omega:X(\omega)\in E\}\bigr).
  \end{aligned}
\]
In particular, for a single value $x$,
\[
  P(X=x):=P\bigl(X^{-1}(\{x\})\bigr).
\]
Here $X$ is the random variable, while $x$ is a particular real number.
\end{frameddefn}

\begin{frameddefn}{Distribution of a random variable}
\label{def:distribution}
The \emph{distribution} of $X$ is the rule that tells us with what
probability $X$ takes values in a given set $E$.
\[
  P_X(E)=P(X\in E).
\]
\end{frameddefn}

The set $E$ contains values; $X^{-1}(E)$ contains the outcomes that
give those values. In our finite examples, every subset of $\Omega$
is an event.

\begin{center}
  \includegraphics[width=0.72\textwidth]{assets/preimage-probability-map.png}
  \par\smallskip
  {\small A preimage and its probability. Illustration from Brutti's slides.}
\end{center}

\Needspace{18\baselineskip}
\begin{framedexample}{Which students have heights in an interval?}
Choose one student uniformly from
$\Omega=\{\text{Anna},\text{Luca},\text{Sara},\text{Marco}\}$.
Let $X$ record height in centimetres:
\[
  \begin{array}{c|rrrr}
    \omega & \text{Anna} & \text{Luca} & \text{Sara} & \text{Marco}\\
    \hline
    X(\omega) & 165 & 178 & 178 & 190
  \end{array}
\]
For $E=[170,180]$, Luca and Sara are the students whose heights fall
inside the interval. Thus
\[
  X^{-1}([170,180])=\{\text{Luca},\text{Sara}\},
  \qquad P(170\leq X\leq180)=\frac24=\frac12.
\]
The same two students also give the exact value $178$:
$X^{-1}(\{178\})=\{\text{Luca},\text{Sara}\}$, so
$P(X=178)=1/2$. One value can correspond to several outcomes.
\end{framedexample}



\Needspace{14\baselineskip}
\begin{framedexample}{Counting heads in two coin tosses}
Toss a fair coin twice, with independent tosses. The four equally
likely outcomes are $\Omega=\{HH,HT,TH,TT\}$, where $H$ means heads
and $T$ means tails. Let $X$ count the heads:
\[
  X(HH)=2,\qquad X(HT)=X(TH)=1,\qquad X(TT)=0.
\]
To get exactly one head, we need either $HT$ or $TH$. Therefore
\[
  X^{-1}(\{1\})=\{HT,TH\},
  \qquad P(X=1)=P(\{HT,TH\})=\frac24=\frac12.
\]
\end{framedexample}

\begin{framedexample}{Counting tails in five coin tosses}
Toss a fair coin five times, with independent tosses. Write $H$ for
heads and $T$ for tails. The sample space is $\Omega=\{H,T\}^5$,
containing $2^5=32$ sequences. Let $X$ count the tails in a sequence,
so its possible values are $0,1,2,3,4,5$.

Each particular sequence has probability $(1/2)^5=1/32$. For example,
$HHHHH$ and $TTHHH$ are equally likely, although they give different
values of $X$.

\textbf{No tails.} Only $HHHHH$ gives zero tails:
\begin{flalign*}
  P(X=0)
    &=P\bigl(X^{-1}(\{0\})\bigr) &&\\
    &=P(\{HHHHH\}) &&\\
    &=\binom50\left(\frac12\right)^5=\frac1{32}. &&
\end{flalign*}
\textbf{One tail.} The tail can occupy any of the five positions:
\begin{flalign*}
  P(X=1)
    &=P\bigl(X^{-1}(\{1\})\bigr) &&\\
    &=P(\{THHHH,HTHHH,HHTHH,HHHTH,HHHHT\}) &&\\
    &=\binom51\left(\frac12\right)^5=\frac5{32}. &&
\end{flalign*}
\textbf{Two tails.} Choose which two of the five positions contain
tails. The corresponding event contains $\binom52=10$ sequences:
\begin{flalign*}
  P(X=2)
    &=P\bigl(X^{-1}(\{2\})\bigr) &&\\
    &=P(\{TTHHH,THTHH,\ldots,HHHTT\}) &&\\
    &=\binom52\left(\frac12\right)^5=\frac{10}{32}. &&
\end{flalign*}
In general, exactly $x$ tails can occur in $\binom5x$ sequences.
Summing their probabilities gives
\[
  \boxed{P(X=x)=P\bigl(X^{-1}(\{x\})\bigr)
    =\binom5x\left(\frac12\right)^5},
  \qquad x\in\{0,1,2,3,4,5\},
\]
The two factors are the number of
sequences with $x$ tails and the probability of each sequence.
\end{framedexample}

\begin{framedexample}{Darts: distance from the centre}\label{ex:darts-areas}
Throw a dart at a circular target of radius $r>0$. Assume that the dart
always hits the disc and that its hitting point is uniform over the
surface: regions with the same area have the same probability of being hit.

Place the centre at the origin. An outcome is the hitting point
$\omega=(u,v)$, so the sample space is
\[
  \Omega=\{(u,v)\in\mathbb R^2:u^2+v^2\leq r^2\}.
\]
Let $X$ measure the distance from that point to the centre:
\[
  X:\Omega\to\mathbb R,
  \qquad X(u,v)=\sqrt{u^2+v^2}.
\]
For a target of radius $10$ cm, some possible outcomes and their distances
are:
\[
  \begin{array}{c|c}
    \text{Hitting point }\omega & \text{Distance }X(\omega)\text{ (cm)}\\
    \hline
    (0,0) & 0\\
    (3,4) & \sqrt{3^2+4^2}=5\\
    (-3,4) & \sqrt{(-3)^2+4^2}=5\\
    (0,10) & 10
  \end{array}
\]
In general, the possible values of $X$ fill the
interval $[0,r]$: zero at the centre, $r$ on the boundary, and any
distance in between.

For the $10$ cm target, asking for a distance of at most $5$ cm selects
the outcomes
\[
  X^{-1}([0,5])
    =\{(u,v)\in\Omega:u^2+v^2\leq25\}.
\]
This is the smaller disc of radius $5$ cm around the centre.

Now choose a distance threshold $x$. For $0\leq x\leq r$, the event
$X\leq x$ means that the dart hits the inner disc of radius $x$.
Since the hitting point is uniform over the target, its probability
is the ratio of the two areas:
\[
  P(X\leq x)
    =\frac{\text{area of the inner disc}}{\text{area of the target}}
    =\frac{\pi x^2}{\pi r^2}
    =\frac{x^2}{r^2}.
\]
A negative threshold is impossible for a distance, while a threshold
larger than $r$ includes the entire target. Thus
\[
  \boxed{P(X\leq x)=
    \begin{cases}
      0, & x<0,\\[2pt]
      x^2/r^2, & 0\leq x\leq r,\\[2pt]
      1, & x>r.
    \end{cases}}
\]
For the target of radius $10$ cm,
\[
  P(X\leq5)=\frac{\pi\cdot5^2}{\pi\cdot10^2}
    =\frac{25}{100}=\frac14.
\]
\end{framedexample}

\section{Discrete random variables}

\begin{frameddefn}{Discrete random variable and PMF}
\label{def:discrete-pmf}
A random variable $X$ is \emph{discrete} if there is a finite or
countably infinite set\begingroup\renewcommand{\thefootnote}{\fnsymbol{footnote}}\footnotemark[1]\endgroup
$\mathcal X=\{x_1,x_2,\ldots\}$ such that
$P(X\in\mathcal X)=1$.

Its \emph{probability mass function} (PMF) is
\[
  p_X(x):=P(X=x),\qquad x\in\mathbb R.
\]
\begin{enumerate}
  \item $p_X(x)\geq0$ for every $x\in\mathbb R$.
  \item The \emph{support}, in the discrete sense used here, is
    $\operatorname{supp}(X):=\{x\in\mathbb R:p_X(x)>0\}$.
    Thus the support lists the values that have positive probability;
    values outside it have probability zero.
  \item $\displaystyle\sum_{x\in\mathcal X}p_X(x)=1$.
\end{enumerate}
\end{frameddefn}

\begingroup
\renewcommand{\thefootnote}{\fnsymbol{footnote}}
\footnotetext[1]{A finite set has finitely many elements. A set $A$ is countably infinite if there exists a bijection $f:\mathbb N\to A$.}
\endgroup

By countable additivity, for any set $E$,
\[
  P(X\in E)=\sum_{x\in E\cap\operatorname{supp}(X)}p_X(x).
\]

\Needspace{17\baselineskip}
\begin{framedexample}{The PMF of a fair die}
Roll a fair six-sided die and let $X$ be the number shown.
The random variable $X$ is discrete because the finite set
$\mathcal X=\{1,2,3,4,5,6\}$ satisfies $P(X\in\mathcal X)=1$.

Its \emph{probability mass function} (PMF) is:
\[
  p_X(x)=
  \begin{cases}
    1/6, & x\in\{1,2,3,4,5,6\},\\
    0, & \text{otherwise}.
  \end{cases}
\]
It satisfies $p_X(x)\geq0$ for every $x$, and
$\sum_{x\in\mathcal X}p_X(x)=6\cdot(1/6)=1$.

Its \emph{support} is $\operatorname{supp}(X)=\{1,2,3,4,5,6\}$,
since each of these values has positive probability. For example,
$p_X(3)=1/6$, whereas $p_X(7)=0$ and $7$ is outside the support.

Let's see an example that shows how to use the PMF to calculate
the probability of an event. To find the probability of rolling
an even number, we add the probabilities of rolling $2$, $4$, or $6$:
\[
  P(X\in\{2,4,6\})=p_X(2)+p_X(4)+p_X(6)
    =\frac16+\frac16+\frac16=\frac12.
\]
\end{framedexample}

\section{Continuous random variables}

\begin{frameddefn}{Continuous random variable and PDF}
\label{def:continuous-pdf}
A random variable $X$ is \emph{continuous} (in the sense used here)
if there exists a function $f_X$, called its \emph{probability density
function} (PDF), such that, for every $a\leq b$,
\[
  P(a\leq X\leq b)=\int_a^b f_X(x)\,dx.
\]
\begin{enumerate}
  \item $f_X(x)\geq0$ for every $x\in\mathbb R$.
  \item Following the convention in the slides, the \emph{support} is
    $\operatorname{supp}(X):=\{x\in\mathbb R:f_X(x)>0\}$.
  \item $\displaystyle\int_{\mathbb R}f_X(x)\,dx=1$.
\end{enumerate}
\end{frameddefn}

\begin{tcolorbox}[notesbox,colframe=red!45,colback=red!3,
  boxed title style={colback=red!25,colframe=red!45},
  title={Note: Heads-up}]
\textbf{A PDF cannot concentrate probability on a countable set.}
First, setting $a=b=x_i$ in the definition gives
\[
  P(X=x_i)=\int_{x_i}^{x_i}f_X(t)\,dt=0:
\]
an interval of zero length has zero area under the PDF.

Now let $A=\{x_1,x_2,\ldots\}$ be any finite or countably infinite
set, listing its elements without repetitions. The event $X\in A$
is the union of the pairwise disjoint events $\{X=x_i\}$. By
countable additivity,
\[
  P(X\in A)=\sum_i P(X=x_i)=\sum_i0=0.
\]
Thus no finite or countably infinite set can contain $X$ with
probability $1$. The existence of a PDF already implies this;
having an uncountable set of possible values alone does not
guarantee that a PDF exists.
\end{tcolorbox}

\Needspace{22\baselineskip}
\begin{framedexample}{Waiting for a bus}
Suppose a bus arrives every $10$ minutes and you reach the stop
at a uniformly random time between two arrivals. Let $X$ be your
waiting time in minutes. Intervals of the same length have the
same probability, so the PDF is constant on $[0,10]$.
Its height is $1/10$, since the total area must be $1$.

Its PDF is:
\[
  f_X(x)=
  \begin{cases}
    1/10, & 0\leq x\leq10,\\
    0, & \text{otherwise}.
  \end{cases}
\]
It satisfies $f_X(x)\geq0$ for every $x$, and
$\int_{\mathbb R}f_X(x)\,dx=\int_0^{10}(1/10)\,dx=1$.

Its \emph{support}, using the convention above, is $[0,10]$.

Let's see an example that shows how to use the PDF to calculate
the probability of an event. The probability of waiting between
$2$ and $5$ minutes is:
\[
  P(2\leq X\leq5)=\int_2^5\frac1{10}\,dx
    =\frac{5-2}{10}=0.30.
\]
\end{framedexample}

\section{Cumulative distribution function (CDF)}

\begin{frameddefn}{Cumulative distribution function}
\label{def:cdf}
Given a random variable $X$, its \emph{cumulative distribution
function} (CDF) is the function $F_X:\mathbb R\to[0,1]$ defined by
\[
  F_X(x):=P(X\leq x)=P\bigl(X\in(-\infty,x]\bigr),
  \qquad x\in\mathbb R.
\]
It gives the probability accumulated up to and including the
threshold $x$. It is defined for both
\hyperref[def:discrete-pmf]{discrete} and
\hyperref[def:continuous-pdf]{continuous} random variables.
\end{frameddefn}

\begin{tcolorbox}[notesbox,colframe=red!45,colback=red!3,boxed title style={colback=red!25,colframe=red!45},title={Proposition: The CDF determines the distribution}]
The CDF contains all the information about the \emph{distribution}
of a random variable. If $F_X(t)=F_Y(t)$ for every $t\in\mathbb R$,
then $X$ and $Y$ have the same distribution: for any set of values
$E$ defining an event,
\[
  P(X\in E)=P(Y\in E).
\]
This does not mean that $X$ and $Y$ must produce the same outcome
in an experiment.
\end{tcolorbox}

\begin{proof}
We prove only a special case of this statement: we show that it
holds for intervals $E=(a,b]$. The full result also holds for any
set $E$ defining an event, but we do not prove that general case here.

Suppose $F_X(t)=F_Y(t)$ for every $t\in\mathbb R$, and let $a<b$.
Since
\[
  \{X\leq b\}=\{X\leq a\}\cup\{a<X\leq b\},
\]
and the two events on the right are disjoint, additivity gives
\[
  P(a<X\leq b)=P(X\leq b)-P(X\leq a)=F_X(b)-F_X(a).
\]
Applying the same reasoning to $Y$ and using the equality of the
two CDFs, we obtain
\[
  \begin{aligned}
    P(X\in E)&=F_X(b)-F_X(a)\\
              &=F_Y(b)-F_Y(a)\\
              &=P(Y\in E).
  \end{aligned}
\]
\end{proof}

\begin{notebox}[PMF and CDF]
The \hyperref[def:discrete-pmf]{PMF} answers:
\emph{``What is the probability that $X$ is exactly $x$?''}
\[
  p_X(x)=P(X=x).
\]
The \hyperref[def:cdf]{CDF} answers:
\emph{``What is the probability that $X$ is at most $x$?''}
\[
  F_X(x)=P(X\leq x).
\]
\end{notebox}

\Needspace{17\baselineskip}
\subsection{Properties of the CDF}

\begin{framedprop}{Properties of the CDF (I)}\label{prop:cdf-properties-i}
A function $F(\cdot)$ mapping the real line to $[0,1]$ is a CDF
for some probability measure $P(\cdot)$ if and only if:
\begin{enumerate}
  \item $F(\cdot)$ is \emph{non-decreasing}: $x_1<x_2$ implies that
    $F(x_1)\leq F(x_2)$.
  \item $F(\cdot)$ is \emph{normalized}:
    \[
      \lim_{x\to-\infty}F(x)=0,
      \qquad
      \lim_{x\to+\infty}F(x)=1.
    \]
  \item $F(\cdot)$ is \emph{right-continuous}: for all $x$ we have
    \[
      F(x)=F(x^+),
      \qquad F(x^+):=\lim_{t\downarrow x}F(t).
    \]
\end{enumerate}
\end{framedprop}

\Needspace{19\baselineskip}
\begin{framedprop}{Properties of the CDF (II/a)}
Let $F_X(\cdot)$ be the CDF of a random variable $X$. Then:
\begin{enumerate}
  \item For $x_1<x_2$,
    \[
      P(x_1<X\leq x_2)=P\bigl(X\in(x_1,x_2]\bigr)
        =F_X(x_2)-F_X(x_1).
    \]
    In the discrete case, be careful with the strict and non-strict
    inequalities.
  \item
    \[
      P(X>x)=P\bigl(X\in(x,+\infty)\bigr)=1-F_X(x).
    \]
  \item If $X$ is continuous with PDF $f_X(\cdot)$, then
    \[
      F_X(x)=\int_{-\infty}^{x}f_X(t)\,dt.
    \]
    A PDF can be recovered from the CDF as
    \[
      f_X(x)=F_X'(x)
    \]
    at points where $F_X$ is differentiable.
\end{enumerate}
\end{framedprop}

\Needspace{20\baselineskip}
\begin{framedprop}{Properties of the CDF (II/b)}
Let $F_X(\cdot)$ be the CDF of a random variable $X$. Then:
\begin{enumerate}
  \item
    \[
      P(x_1<X\leq x_2)=P\bigl(X\in(x_1,x_2]\bigr)
        =F_X(x_2)-F_X(x_1),\qquad x_1<x_2.
    \]
  \item
    \[
      P(X>x)=P\bigl(X\in(x,+\infty)\bigr)=1-F_X(x).
    \]
  \item If $X$ is discrete with PMF $p_X(\cdot)$ and support
    $\mathcal X=\{x_1,x_2,\ldots\}$, then
    \[
      F_X(x)=\sum_{x_i\leq x}p_X(x_i)=P(X<x)+p_X(x).
    \]
    Hence
    \[
      p_X(x)=F_X(x)-F_X(x^-),
      \qquad F_X(x^-):=\lim_{t\uparrow x}F_X(t).
    \]
\end{enumerate}
\end{framedprop}

\Needspace{15\baselineskip}
Let $F_X(\cdot)$ be the CDF of a continuous random variable with PDF
$f_X(\cdot)$. The following informal observations motivate later
nonparametric statistical developments:
\begin{enumerate}
  \item Roughly speaking, $F_X(\cdot)$ is ``simpler'' than $f_X(\cdot)$.
  \item It must be non-decreasing, so its shape is more constrained
    than that of a PDF.
  \item Integration accumulates and smooths the PDF, making the CDF
    more regular.
  \item This suggests that estimating the CDF is easier than estimating
    the PDF: fewer observations may be needed to reach the same
    statistical accuracy.
\end{enumerate}

\begin{framedexample}{Darts: from areas to the CDF and PDF}
Return to the \hyperref[ex:darts-areas]{earlier darts example}, with
a disc of radius $10$ cm and a hitting point uniform over its area.
Let $X$ be the distance from the centre in centimetres.
Earlier, we obtained $P(X\leq x)$ using areas. Now we recognise
this function as the CDF, differentiate it to find a PDF, and use
that PDF to calculate probabilities of intervals.

\textbf{1. Recognise the CDF.}
The function calculated earlier is the CDF:
\[
  F_X(x)=P(X\leq x)=
  \begin{cases}
    0, & x<0,\\
    x^2/100, & 0\leq x\leq10,\\
    1, & x>10.
  \end{cases}
\]

\textbf{2. Derive the PDF.}
The PDF is not given. We find it by differentiating the CDF for
$0<x<10$:
\[
  f_X(x)=F_X'(x)
    =\frac{d}{dx}\left(\frac{x^2}{100}\right)
    =\frac{2x}{100}=\frac{x}{50}.
\]
Its PDF is:
\[
  f_X(x)=
  \begin{cases}
    x/50, & 0\leq x\leq10,\\
    0, & \text{otherwise}.
  \end{cases}
\]
This PDF reproduces the probabilities of the model. It is non-negative
and satisfies
\[
  \int_{\mathbb R}f_X(x)\,dx
    =\int_0^{10}\frac{x}{50}\,dx
    =\left[\frac{x^2}{100}\right]_0^{10}=1.
\]
Its support, with the convention used above and this choice of PDF,
is $(0,10]$.

\textbf{3. Use the PDF to calculate an interval probability.}
Now that we have derived the PDF, we can, for example, calculate the
probability that the dart lands between $5$ and $8$ cm from the centre:
\[
  P(5\leq X\leq8)
    =\int_5^8\frac{x}{50}\,dx
    =\left[\frac{x^2}{100}\right]_5^8
    =\frac{64-25}{100}=0.39.
\]
The CDF gives the same result:
$F_X(8)-F_X(5)=0.64-0.25=0.39$.

For the two intervals used in the slides, the same method gives
\[
  P(0<X\leq5)=\int_0^5\frac{x}{50}\,dx=\frac14,
  \qquad
  P(5<X\leq10)=\int_5^{10}\frac{x}{50}\,dx=\frac34.
\]
\end{framedexample}

\section{Relations}
\subsection{From the PMF to the CDF}
\begin{tcolorbox}[colback=blue!3,colframe=blue!30!black,
  boxrule=0.4pt,arc=1mm,title={What we are trying to answer},
  colbacktitle=blue!10,coltitle=black,fonttitle=\bfseries]
If we know the probability of each individual
value of $X$, how do we calculate the probability that $X$ is at most $x$?
\end{tcolorbox}

For a discrete random variable, the event $X\leq x$ includes every
possible value $k$ that is at most $x$. These events $\{X=k\}$ are
pairwise disjoint, so we add their probabilities:
\[
  \boxed{\underbrace{F_X(x)}_{\text{CDF: to find}}=P(X\leq x)
    =\sum_{\substack{k\in\operatorname{supp}(X)\\k\leq x}}
      \underbrace{p_X(k)}_{\text{PMF: known}},
    \qquad x\in\mathbb R.}
\]
\subsection{From the PDF to the CDF}
\label{rel:pdf-to-cdf}
\begin{tcolorbox}[colback=blue!3,colframe=blue!30!black,
  boxrule=0.4pt,arc=1mm,title={What we are trying to answer},
  colbacktitle=blue!10,coltitle=black,fonttitle=\bfseries]
We know how probability is spread over the possible values of $X$
(its PDF). How do we calculate the probability of getting a value
less than or equal to $x$?
\end{tcolorbox}
For a continuous random variable with PDF $f_X$, we calculate
$P(X\leq x)$ by integrating the PDF over $(-\infty,x]$:
\[
  \boxed{\underbrace{F_X(x)}_{\text{CDF: to find}}=P(X\leq x)
    =\int_{-\infty}^{x}\underbrace{f_X(t)}_{\text{PDF: known}}\,dt,
    \qquad x\in\mathbb R.}
\]
\Needspace{27\baselineskip}
\subsection{From the CDF to the PMF and PDF}
\begin{tcolorbox}[colback=blue!3,colframe=blue!30!black,
  boxrule=0.4pt,arc=1mm,title={What we are trying to answer},
  colbacktitle=blue!10,coltitle=black,fonttitle=\bfseries]
We know the CDF $F_X$. How do we recover the PMF $p_X$ if $X$ is
discrete, or the PDF $f_X$ if $X$ is continuous?
\end{tcolorbox}

\textbf{What we know.} The CDF is defined by
\[
  F_X(x):=P(X\leq x).
\]
For every threshold $x$, it gives the probability of obtaining a
value less than or equal to $x$. We want to recover the PMF or the
PDF, depending on the type of $X$.

\textbf{Discrete case: recover the PMF.}
The PMF is defined by
\[
  p_X(x):=P(X=x).
\]
The CDF includes all values up to $x$. To isolate the probability
of the single value $x$, we subtract the probability of values
strictly less than $x$:
\[
  P(X=x)=P(X\leq x)-P(X<x).
\]
Since the left limit satisfies
\[
  F_X(x^-):=\lim_{t\uparrow x}F_X(t)=P(X<x),
\]
we obtain
\[
  \boxed{\underbrace{p_X(x)}_{\text{PMF: to find}}
    =\underbrace{F_X(x)-F_X(x^-)}_{\text{CDF: known}}.}
\]
Thus the PMF at $x$ is the size of the jump of the CDF at $x$.

\textbf{Continuous case: recover the PDF.}
A PDF is a non-negative function $f_X$ such that
\[
  P(a\leq X\leq b)=\int_a^b f_X(t)\,dt,
  \qquad \int_{\mathbb R}f_X(t)\,dt=1.
\]
In particular,
\[
  F_X(x)=P(X\leq x)=\int_{-\infty}^{x}f_X(t)\,dt.
\]
The CDF is therefore the integral of the PDF. To recover a PDF,
we differentiate the CDF:
\[
  \boxed{\underbrace{f_X(x)}_{\text{PDF: to find}}
    =\frac{d}{dx}\underbrace{F_X(x)}_{\text{CDF: known}}.}
\]
This recovers a PDF at points where the derivative exists, by the
fundamental theorem of calculus.

\section{The quantile function}
\begin{tcolorbox}[colback=blue!3,colframe=blue!30!black,
  boxrule=0.4pt,arc=1mm,title={What we are trying to answer},
  colbacktitle=blue!10,coltitle=black,fonttitle=\bfseries]
Given a probability $p$, which threshold $x$ satisfies
$P(X\leq x)=p$?
\end{tcolorbox}
The CDF starts with a threshold and returns a probability. The
quantile function starts with a probability and returns a threshold.
For example, the $90$th percentile is a threshold below which
$90\%$ of the probability lies; the median is the quantile at level $0.5$.

\begin{frameddefn}{Quantile function: continuous case}
\label{def:quantile-continuous}
Let $X$ be a continuous random variable with CDF $F_X$. For a
probability level $0<p<1$, its \emph{quantile function} is
\[
  Q(p):=\inf\{x\in\mathbb R:F_X(x)=p\}.
\]
It gives the smallest value $x$ such that $F_X(x)=P(X\leq x)=p$.
We also write $q_p$ instead of $Q(p)$.
\end{frameddefn}
The symbol $\inf$ denotes the infimum (greatest lower bound);
when the set has a minimum, the infimum is its smallest element.
Here we consider levels strictly between $0$ and $1$; endpoint
levels may require separate conventions.

\textbf{Geometric interpretation.}
Start at height $p$ on the vertical axis, move horizontally to the
CDF, and then read the corresponding threshold on the horizontal
axis. If several thresholds give the same probability, choose
the smallest one.

In this continuous CDF, every threshold in $[a,b]$ gives the same
probability $p$. Thus $\{x:F_X(x)=p\}=[a,b]$ and $Q(p)=a$.

When the CDF is strictly increasing between probability levels
$0$ and $1$, each level corresponds to a unique threshold. The CDF
is therefore invertible on this range, so
\[
  \boxed{Q(p)=F_X^{-1}(p).}
\]
An inverse may exist without a simple explicit formula. In that
case, quantiles can be calculated numerically.

\Needspace{18\baselineskip}
\textbf{A more general definition.}
If the CDF has a jump, it may skip the level $p$, so the equation
$F_X(x)=p$ may have no solution. We therefore replace equality
with $F_X(x)\geq p$.

\begin{frameddefn}{Quantile function: general case}
\label{def:quantile-general}
Let $X$ be any random variable, discrete or continuous, with CDF
$F_X$. For a probability level $0<p<1$, its \emph{quantile function} is
\[
  Q(p):=\inf\{x\in\mathbb R:F_X(x)\geq p\}.
\]
It gives the smallest threshold $x$ such that
$P(X\leq x)$ is at least $p$. We also write $q_p$ instead of $Q(p)$.
\end{frameddefn}

At a jump, the quantile is the first threshold where the CDF
reaches or exceeds $p$; the probability there may be greater than $p$.
If the CDF has a plateau at level $p$, this definition chooses its
left endpoint. This is the lower-quantile convention used here.
If the CDF is invertible, $Q(p)=F_X^{-1}(p)$ (see
\hyperref[def:quantile-continuous]{Definition~\ref*{def:quantile-continuous}}).

\begin{framedexample}{Reading a quantile across a jump}
\label{ex:quantile-jump}

\begin{notebox}[Quantiles as areas under the PDF]
\label{note:quantile-pdf-area}
\textbf{What we are trying to answer.}
We know the PDF and choose a probability $p$. Where should we stop
so that the area under the PDF to the left is $p$?

For a continuous random variable with a PDF, we already know the
\hyperref[rel:pdf-to-cdf]{relation between the PDF and the CDF}:
\[
  F_X(x)=P(X\leq x)=\int_{-\infty}^{x}f_X(t)\,dt.
\]
Previously, we fixed the threshold $x$ and calculated the probability.
Now we fix the probability $p$ and look for the threshold $q_p=Q(p)$.
Since the CDF is continuous, $F_X(q_p)=p$, so
\[
  \underbrace{p}_{\text{chosen probability}}
  =F_X(q_p)
  =\int_{-\infty}^{\underbrace{q_p}_{\text{threshold: to find}}}
    \underbrace{f_X(t)}_{\text{PDF: known}}\,dt.
\]
Thus we find $q_p$ by solving this equation. If several thresholds
give the same area, the
\hyperref[def:quantile-general]{general quantile definition}
chooses the smallest one.

For the median, $p=0.5$: we look for the threshold that leaves
half of the total area under the PDF to its left.
\end{notebox}

\begin{framedexample}{Quantiles of a Pareto distribution}
\label{ex:pareto-quantiles}
The slides give a continuous random variable with CDF
\[
  F_X(x)=
  \begin{cases}
    0, & x<1,\\
    1-x^{-\alpha}, & x\geq1,
  \end{cases}
  \qquad \alpha>0.
\]
This is a Pareto distribution with shape parameter $\alpha$ and
scale parameter $1$. For example, if $\alpha=1/2$, suppose we want
to find the $20$th percentile and the median.

\textbf{1. Recover the PDF.}
For $x>1$, we differentiate the given CDF:
\[
  f_X(x)=F_X'(x)=\alpha x^{-\alpha-1}.
\]
We may therefore choose
\[
  f_X(x)=
  \begin{cases}
    \alpha/x^{\alpha+1}, & x\geq1,\\
    0, & x<1.
  \end{cases}
\]

\textbf{2. Find the quantile function.}
The CDF is strictly increasing for $x\geq1$. For $0<p<1$,
we find the unique threshold $q_p$ by solving $F_X(q_p)=p$:
\[
  \begin{aligned}
    p&=1-q_p^{-\alpha},\\
    q_p^{-\alpha}&=1-p,\\
    q_p^{\alpha}&=\frac{1}{1-p},\\
    q_p&=\left(\frac{1}{1-p}\right)^{1/\alpha}.
  \end{aligned}
\]
Thus the whole quantile function is
\[
  \boxed{Q(p)=F_X^{-1}(p)=(1-p)^{-1/\alpha},\qquad 0<p<1.}
\]

\textbf{3. Calculate the requested quantiles with $\alpha=1/2$.}
Here $1/\alpha=2$, so $Q(p)=(1-p)^{-2}$.
For the $20$th percentile, we choose $p=0.20$:
\[
  \boxed{q_{0.20}=(1-0.20)^{-2}
    =\frac{1}{0.8^2}=1.5625\approx1.56.}
\]
Hence $P(X\leq1.5625)=0.20$.
For the median (the second quartile), we choose $p=0.50$:
\[
  \boxed{q_{0.50}=(1-0.50)^{-2}
    =\frac{1}{0.5^2}=4.}
\]
Hence $P(X\leq4)=0.50$: the threshold $4$ leaves half of the
probability to its left.
\end{framedexample}

\section{Common univariate distributions}

\subsection{The uniform distribution}
\label{sec:uniform-distribution}
A \textbf{uniform distribution} assigns the same probability to
intervals of the same length within its support. Its parameters
$a$ and $b$ specify the ends of that support.

\begin{frameddefn}{Uniform distribution}
\label{def:uniform-distribution}
A continuous random variable $X$ has a \emph{uniform distribution}
with parameters $a<b$, where $a,b\in\mathbb R$, if its PDF and CDF
are
\[
  f_X(x)=\frac{1}{b-a}\mathbf 1_{[a,b]}(x),
\]
\[
  F_X(x)=
  \begin{cases}
    0, & x<a,\\
    \dfrac{x-a}{b-a}, & a\leq x\leq b,\\
    1, & x>b.
  \end{cases}
\]
We denote this distribution by $\operatorname{Unif}(a,b)$ and write
$X\sim\operatorname{Unif}(a,b)$. Here $\operatorname{Unif}$
abbreviates \emph{uniform}, and $\sim$ means \emph{has distribution}.
\end{frameddefn}

\textbf{Why is the density a rectangle?} Uniformity means that
intervals of the same length within $[a,b]$ have the same
probability, hence the same area under the PDF. If the density
were higher in one region, a small interval there would have
more probability than an equally long interval in a lower region.
The density is therefore constant on $[a,b]$ and zero outside it.
Its graph is horizontal on the support, so the region beneath it
is a rectangle: the rectangular shape follows from uniformity,
before we calculate its height.

\textbf{Why is the height $1/(b-a)$?} Let $h$ be the constant
height. The rectangle has width $b-a$, and the total area under
a PDF must be $1$:
\[
  h(b-a)=1\qquad\Longrightarrow\qquad h=\frac{1}{b-a}.
\]
For $a\leq c\leq d\leq b$,
\[
  P(c\leq X\leq d)=\int_c^d\frac{1}{b-a}\,dx
    =\frac{d-c}{b-a}.
\]
The numerator is the length of the selected interval; the
denominator is the length of the full support.\newline
For $a\leq x\leq b$, the same calculation gives the CDF:
\[
  F_X(x)=\int_a^x\frac{1}{b-a}\,dt=\frac{x-a}{b-a}.
\]

\subsubsection{The standard uniform distribution: $\operatorname{Unif}(0,1)$}
\label{sec:uniform-standard}
The \textbf{standard uniform distribution}, written
$U\sim\operatorname{Unif}(0,1)$, is the \textbf{special case} of
the general $\operatorname{Unif}(a,b)$ distribution in
Section~\ref{sec:uniform-distribution} obtained by setting $a=0$
and $b=1$.\newline
Its support is therefore $[0,1]$, and substituting
these endpoints gives the constant density
$1/(b-a)=1/(1-0)=1$. Its PDF is
\[
  f_U(u)=
  \begin{cases}
    1, & 0\leq u\leq1,\\
    0, & \text{otherwise}.
  \end{cases}
\]
For $0\leq c\leq d\leq1$,
\[
  P(c\leq U\leq d)=\int_c^d1\,du=d-c.
\]

\textbf{Find the CDF.} By the
\hyperref[def:cdf]{definition of a CDF}, $F_U(t)=P(U\leq t)$.
For $0\leq t\leq1$, integrate the PDF up to $t$:
\[
  \boxed{F_U(t)=P(U\leq t)=\int_0^t1\,du=t.}
\]
This also follows directly from the general CDF formula:
$(t-a)/(b-a)=(t-0)/(1-0)=t$ for $0\leq t\leq1$.
The full CDF is therefore
\[
  F_U(t)=
  \begin{cases}
    0, & t<0,\\
    t, & 0\leq t\leq1,\\
    1, & t>1.
  \end{cases}
\]
For example, $P(U\leq0.3)=0.3$: the interval from $0$ to $0.3$
contains $30\%$ of the probability. Geometrically, this is a
rectangle with width $0.3$ and height $1$, so its area is $0.3$.

\section{Random vectors and the plan of study}

\begin{frameddefn}{Random vector}
On a common probability space $(\Omega,\mathcal F,P)$, a
\textbf{random vector} is a vector of random variables
\[
  \mathbf X:\Omega\longrightarrow\mathbb R^p,
  \qquad
  \mathbf X(\omega)=
  \begin{pmatrix}
    X_1(\omega)\\
    \vdots\\
    X_p(\omega)
  \end{pmatrix}.
\]
The integer $p$ is the dimension of the vector. Each component
$X_j:\Omega\to\mathbb R$ is a random variable.
\end{frameddefn}

There are three related tasks:
\begin{enumerate}
  \item Describe the \textbf{joint distribution} of the whole vector.
  \item Describe the distribution of each component separately:
    \textbf{univariate analysis}.
  \item Study how the components interact or depend on one another:
    \textbf{multivariate analysis}.
\end{enumerate}

We start with \textbf{fully discrete vectors} and $p=2$: define
the joint PMF, then derive marginal and conditional PMFs.
The later cases are continuous vectors (using a joint PDF when
one exists) and mixed vectors, with discrete and continuous
components. Continuous marginals alone need not give a joint PDF.

\clearpage
\section{The joint PMF}
\label{sec:joint-pmf}

Let $\mathbf Z=(X,Y)^{\mathsf T}$, where $X$ and $Y$ are discrete,
with supports $S_X$ and $S_Y$.

\begin{frameddefn}{Joint probability mass function}
The \textbf{joint PMF} assigns a probability to each pair of values:
\[
  p_{X,Y}(x,y)=P(X=x,Y=y)
    =P\bigl(\{X=x\}\cap\{Y=y\}\bigr).
\]
It satisfies
\[
  p_{X,Y}(x,y)\geq0,
  \qquad
  \sum_{x\in S_X}\sum_{y\in S_Y}p_{X,Y}(x,y)=1.
\]
Some pairs in $S_X\times S_Y$ may have probability zero.
The joint PMF completely determines the distribution of $(X,Y)$.
\end{frameddefn}

\begin{framedexample}{Exam result and class attendance}
Let $X=1$ mean that a student passes the exam and $X=0$ mean
that the student fails. Let $Y$ record class attendance:
Always (A), Never (N), or Sometimes (S).
These categories may be coded as $0$, $1$, and $2$, respectively;
the numerical labels are just codes.

The joint PMF is given by the following \textbf{contingency table}.
Each interior cell is the probability of the corresponding pair.
\begin{center}
\begin{tabular}{lrrrr}
\toprule
 & A & N & S & Total\\
\midrule
Pass ($X=1$) & $0.09$ & $0.20$ & $0.01$ & $0.30$\\
Fail ($X=0$) & $0.05$ & $0.60$ & $0.05$ & $0.70$\\
\midrule
Total & $0.14$ & $0.80$ & $0.06$ & $1.00$\\
\bottomrule
\end{tabular}
\end{center}
For example, $P(X=1,Y=\mathrm A)=0.09$: the probability that
a student both passes and always attends is $0.09$.
All six interior cells together sum to $1$.
\end{framedexample}

\section{Marginal and conditional PMFs}
\label{sec:marginal-conditional-pmf}

\subsection{Marginalization}

To study $X$ alone, we add the probabilities of all pairs with
that value of $X$, allowing $Y$ to take any of its possible values.

\begin{framedprop}{Marginal PMFs}
The marginal distributions are obtained by summing out the
other variable:
\[
  p_X(x)=\sum_{y\in S_Y}p_{X,Y}(x,y),
  \qquad
  p_Y(y)=\sum_{x\in S_X}p_{X,Y}(x,y).
\]
\end{framedprop}

For a fixed $x$, the events $\{X=x,Y=y\}$ are disjoint as $y$
varies, and their union is $\{X=x\}$. Hence
\[
  P(X=x)=\sum_{y\in S_Y}P(X=x,Y=y).
\]
In the table, marginalization means taking row or column totals.

For the exam example,
\begin{align*}
  p_X(1)&=0.09+0.20+0.01=0.30,\\
  p_X(0)&=0.05+0.60+0.05=0.70.
\end{align*}
Thus $X\sim\operatorname{Ber}(0.30)$, with passing as the success
outcome. \textbf{TODO:} Review this notation after covering the
\hyperref[sec:bernoulli-distribution]{Bernoulli distribution in
Section~\ref{sec:bernoulli-distribution}}.

For attendance,
\begin{align*}
  p_Y(\mathrm A)&=0.09+0.05=0.14,\\
  p_Y(\mathrm N)&=0.20+0.60=0.80,\\
  p_Y(\mathrm S)&=0.01+0.05=0.06.
\end{align*}
The marginal PMFs describe the individual variables, but they
do not retain all the information in the joint table.

\subsection{Conditioning}

Suppose attendance is known. We then describe exam results
\emph{within that attendance group}. The conditioning value is
fixed, and probabilities are renormalized within that group.

\begin{frameddefn}{Conditional PMFs}
For a value $y$ with $p_Y(y)>0$,
\[
  p_{X\mid Y}(x\mid y)
    =P(X=x\mid Y=y)
    =\frac{p_{X,Y}(x,y)}{p_Y(y)}.
\]
Similarly, for $x$ with $p_X(x)>0$,
\[
  p_{Y\mid X}(y\mid x)
    =P(Y=y\mid X=x)
    =\frac{p_{X,Y}(x,y)}{p_X(x)}.
\]
For each fixed conditioning value, the conditional probabilities
are nonnegative and sum to $1$ over the remaining variable.
\end{frameddefn}

Among students who always attend,
\begin{align*}
  P(X=1\mid Y=\mathrm A)&=\frac{0.09}{0.14}
    =\frac9{14}\approx0.643,\\
  P(X=0\mid Y=\mathrm A)&=\frac{0.05}{0.14}
    =\frac5{14}\approx0.357.
\end{align*}
Among students who never attend,
\[
  P(X=1\mid Y=\mathrm N)=\frac{0.20}{0.80}=0.25,
  \qquad
  P(X=0\mid Y=\mathrm N)=\frac{0.60}{0.80}=0.75.
\]
The same calculation for the remaining column gives
\[
  P(X=1\mid Y=\mathrm S)=\frac{0.01}{0.06}=\frac16,
  \qquad
  P(X=0\mid Y=\mathrm S)=\frac{0.05}{0.06}=\frac56.
\]
Thus each conditional distribution is
\hyperref[sec:bernoulli-distribution]{Bernoulli}:
\[
  X\mid(Y=y)\sim\operatorname{Ber}\bigl(\pi(y)\bigr),
  \qquad \pi(y)=P(X=1\mid Y=y).
\]
Its success probability depends on the attendance group.
In particular, $0.643$, $0.25$, and $1/6$ differ from the
marginal success probability $0.30$.

\section{Independence and the role of dependence}
\label{sec:random-vector-independence}

\begin{frameddefn}{Independence of discrete random variables}
Two discrete random variables $X$ and $Y$ are independent if
and only if
\[
  p_{X,Y}(x,y)=p_X(x)p_Y(y)
  \qquad\text{for every }(x,y)\in S_X\times S_Y.
\]
Equivalently,
\[
  p_{X\mid Y}(x\mid y)=p_X(x)
  \quad\text{for every }x
  \text{ and every }y\text{ with }p_Y(y)>0.
\]
\end{frameddefn}

Under independence, knowing one variable does not change the
distribution of the other. The factorization must hold for
every pair of values.

The original exam table is not independent, because
\[
  p_{X,Y}(1,\mathrm A)=0.09
  \neq 0.30\cdot0.14=0.042.
\]

\textbf{An independent table with the same marginals.}

Keep the same row and column totals, and define a new joint PMF
by multiplying the marginals:
\[
  \widetilde p_{X,Y}(x,y)=p_X(x)p_Y(y).
\]
This gives
\begin{center}
\begin{tabular}{lrrrr}
\toprule
 & A & N & S & Total\\
\midrule
Pass ($X=1$) & $0.042$ & $0.240$ & $0.018$ & $0.300$\\
Fail ($X=0$) & $0.098$ & $0.560$ & $0.042$ & $0.700$\\
\midrule
Total & $0.140$ & $0.800$ & $0.060$ & $1.000$\\
\bottomrule
\end{tabular}
\end{center}
For instance, $\widetilde p_{X,Y}(0,\mathrm S)=0.70\cdot0.06
=0.042$. Every conditional passing probability in this new
table is $0.30$.

\textbf{How far are we from independence?}

The two tables have identical marginals but different joint
distributions. This shows that the marginals alone do not
determine the dependence between the variables.

One way to study departures from independence is to compare the
actual joint PMF with the independent one:
\[
  D\bigl(p_{X,Y},\widetilde p_{X,Y}\bigr),
  \qquad \widetilde p_{X,Y}=p_Xp_Y.
\]
Here $D$ denotes a chosen discrepancy between distributions.
Different choices emphasize different departures from independence.

The next question is whether we can describe a joint distribution
through its marginals together with a separate dependence
structure. This motivates copulas. We first introduce the joint CDF.

\section{The joint CDF}
\label{sec:joint-cdf}

\begin{frameddefn}{Joint cumulative distribution function}
For any pair of random variables, discrete or otherwise,
\[
  F_{X,Y}(x,y)=P(X\leq x,Y\leq y),
  \qquad (x,y)\in\mathbb R^2.
\]
This is the probability of the lower-left region
$(-\infty,x]\times(-\infty,y]$ in the plane.
\end{frameddefn}

\subsection{Recovering the marginals}
Letting one threshold tend to $+\infty$ removes its restriction:
\[
  F_X(x)=\lim_{y\to+\infty}F_{X,Y}(x,y),
  \qquad
  F_Y(y)=\lim_{x\to+\infty}F_{X,Y}(x,y).
\]
This is marginalization expressed through CDFs rather than PMFs.

\subsection{Basic properties}
The joint CDF takes values in $[0,1]$, is nondecreasing in each
coordinate, and is right-continuous. It tends to $0$ when either
threshold tends to $-\infty$, and to $1$ when both tend to $+\infty$.

In two dimensions, probabilities of rectangles must also be
nonnegative. For $a<b$ and $c<d$,
\begin{align*}
  P(a<X\leq b,\ c<Y\leq d)
    &=F_{X,Y}(b,d)-F_{X,Y}(a,d)\\
    &\quad-F_{X,Y}(b,c)+F_{X,Y}(a,c)\geq0.
\end{align*}
This is called the \textbf{2-increasing property}; being
nondecreasing separately in each coordinate is not sufficient.

For arbitrary random variables, independence is equivalent to
\[
  F_{X,Y}(x,y)=F_X(x)F_Y(y)
  \qquad\text{for all }x,y\in\mathbb R.
\]

\section{Copulas and Sklar's theorem}
\label{sec:copulas}

The marginals describe the individual variables. A copula
provides a way to combine those marginals into a joint CDF,
accounting for their dependence.

\begin{frameddefn}{Bivariate copula}
A \textbf{copula} is a joint CDF of two random variables with
standard uniform marginals:
\[
  C(u,v)=P(U\leq u,V\leq v),
  \qquad U,V\sim\operatorname{Unif}(0,1).
\]
The variables $U$ and $V$ need not be independent. On $[0,1]^2$,
the marginal conditions are $C(u,1)=u$ and $C(1,v)=v$.
\end{frameddefn}

\begin{framedthm}{Sklar's theorem: bivariate form}
For any joint CDF $F_{X,Y}$ with marginals $F_X$ and $F_Y$,
there exists a copula $C$ such that
\[
  F_{X,Y}(x,y)=C\bigl(F_X(x),F_Y(y)\bigr).
\]
If both marginals are continuous, the copula is unique. Otherwise,
it is uniquely determined only on
$\operatorname{Ran}(F_X)\times\operatorname{Ran}(F_Y)$, the product
of the sets of values taken by the marginal CDFs.

Conversely, combining any two marginal CDFs with a copula using
this formula produces a joint CDF with those marginals.
\end{framedthm}

The lecture's schematic statement
\[
  \text{joint distribution}
  =\text{marginals}+\text{dependence structure}
\]
is made precise by this composition. The plus sign in the
schematic statement does not mean addition of CDFs.

For independence, the \textbf{independence copula} is
\[
  C_{\perp}(u,v)=uv.
\]
Substituting the marginals gives
\[
  F_{X,Y}(x,y)=C_{\perp}\bigl(F_X(x),F_Y(y)\bigr)
    =F_X(x)F_Y(y).
\]
This is the CDF counterpart of the independent PMF table.

\section{IID samples from a population}
\label{sec:iid-sample}

We now connect population distributions to the data used in
statistical learning. Let $F_X$ be the CDF of a population
variable $X$. A sampling scheme produces observations from that
population.

\begin{frameddefn}{Independent and identically distributed sample}
A random sample $(X_1,\ldots,X_n)$ is \textbf{IID} from $F_X$ if
\begin{itemize}
  \item the random variables $X_1,\ldots,X_n$ are mutually
    independent;
  \item each $X_i$ has the same CDF $F_X$.
\end{itemize}
Here $n$ is the sample size. Uppercase $X_i$ denotes a random
observation before sampling; lowercase $x_i$ denotes its observed
value. The realized dataset is $\mathcal D_n=(x_1,\ldots,x_n)$.
\end{frameddefn}

\subsection{The joint CDF of the sample}
Independence gives a product, and identical distribution gives
the same CDF in every factor:
\begin{align*}
  F_{X_1,\ldots,X_n}(x_1,\ldots,x_n)
    &=P(X_1\leq x_1,\ldots,X_n\leq x_n)\\
    &=\prod_{i=1}^n P(X_i\leq x_i)\\
    &=\prod_{i=1}^n F_X(x_i).
\end{align*}
This is the probability that \emph{all} observations lie below
their respective thresholds.

\subsection{Multivariate observations}
Each observation may itself be a vector
$\mathbf X_i\in\mathbb R^p$. If these vectors are IID with common
joint CDF $F_{\mathbf X}$, then
\[
  P(\mathbf X_1\leq\mathbf x_1,\ldots,
     \mathbf X_n\leq\mathbf x_n)
    =\prod_{i=1}^n F_{\mathbf X}(\mathbf x_i),
\]
where each vector inequality is interpreted componentwise.
The product is over observations. Coordinates within one
observation may still be dependent.

Thus $n$ counts observations, whereas $p$ counts variables in
each observation.

\clearpage
\section{Likelihood and the empirical distribution}
\label{sec:likelihood-empirical}

The learning problem reverses the sampling perspective: after
observing $\mathcal D_n$, we want to learn about the population
distribution that generated it.

\begin{notebox}[Joint CDF and likelihood]
The product $\prod_iF_X(x_i)$ above is the joint CDF evaluated
at thresholds. For exact observations, the usual IID likelihood
is instead a product of \textbf{PMF or PDF values}.
The two objects must be distinguished when reading the
handwritten notes.
\end{notebox}

\subsection{Maximum likelihood estimation}
Consider a model indexed by an unknown parameter $\theta\in\Theta$.
For fixed observed data, its \textbf{likelihood} is
\[
  L(\theta;x_1,\ldots,x_n)=
  \begin{cases}
    \displaystyle\prod_{i=1}^n p_\theta(x_i),
       & \text{discrete model},\\[6pt]
    \displaystyle\prod_{i=1}^n f_\theta(x_i),
       & \text{model with a PDF}.
  \end{cases}
\]
Here $p_\theta$ or $f_\theta$ describes one population observation.
In the continuous case, a PDF value is a density, not the
probability of that exact observed value.

The data stay fixed while we vary the model parameter. A
\textbf{maximum likelihood estimator (MLE)} chooses a maximizer:
\[
  \widehat\theta_n\in
  \argmax_{\theta\in\Theta}L(\theta;x_1,\ldots,x_n),
\]
when a maximizer exists. Equivalently, one may maximize the
log-likelihood, which turns products into sums.

\clearpage
\subsection{The empirical CDF and its likelihood interpretation}

\begin{frameddefn}{Empirical cumulative distribution function}
Given observations $x_1,\ldots,x_n$, the \textbf{empirical CDF}
is
\[
  \widehat F_n(t)=\frac1n\sum_{i=1}^n
    \mathbf 1_{\{x_i\leq t\}}.
\]
It is the fraction of observations at or below $t$.
The corresponding empirical distribution assigns mass $1/n$
to each observation, counting repetitions.
\end{frameddefn}

To make the MLE interpretation precise, consider discrete
distributions supported on the \emph{distinct observed values}
$z_1,\ldots,z_m$. Let $n_j$ count how many observations equal
$z_j$, and let $w_j$ be the model's probability mass there.
Then
\[
  w_j\geq0,\qquad \sum_{j=1}^m w_j=1,
  \qquad \sum_{j=1}^m n_j=n.
\]
The exact-observation likelihood is
\[
  L(w_1,\ldots,w_m)=\prod_{j=1}^m w_j^{n_j}.
\]
Maximizing it subject to the probability constraints gives
\[
  \widehat w_j=\frac{n_j}{n}.
\]
Indeed, the log-likelihood is $\sum_j n_j\log w_j$.
Introducing a multiplier $\lambda$ for $\sum_jw_j=1$ gives
$n_j/w_j=\lambda$; summing $w_j=n_j/\lambda$ yields $\lambda=n$.
Concavity of the log-likelihood ensures that these weights
maximize it.

The resulting CDF is exactly
\[
  \sum_{j=1}^m\frac{n_j}{n}\mathbf 1_{\{z_j\leq t\}}
    =\widehat F_n(t).
\]
This is the discrete nonparametric likelihood interpretation of
the empirical distribution. It is not obtained by maximizing a
product of CDF values, nor by freely maximizing over all
continuous PDFs.

\section{A ``what if?'' experiment}
\label{sec:simulation-what-if}
A ``what if?'' question asks what would happen in a hypothetical
situation. A simulation reproduces possible outcomes of an experiment
on a computer. We can repeat the simulation and observe what happens
across the different repetitions.

\begin{framedexample}{One hundred coin tosses}
Suppose we ask:
\begin{quote}
If I tossed a coin $100$ times, how many heads would I get?
\end{quote}
A simulation produces a possible sequence of $100$ tosses, and we
count the heads in that sequence. We can repeat this experiment
on the computer and compare the numbers of heads obtained.
\end{framedexample}

\section{From a real coin to a simulation}
Imagine that we have a coin, but we do not know its probability of
landing heads. For each toss, let $X=1$ mean heads and $X=0$ mean tails.
Its distribution is described by
\[
  P(X=1)=p,\qquad P(X=0)=1-p,
\]
where $p$ is unknown. This is our \textbf{population model}: it
describes the possible outcomes and their probabilities.

We decide to toss the coin $100$ times. We assume that the tosses are
independent and that each has the same probability $p$ of heads.
This is our \textbf{sampling scheme}. We call the tosses
\textbf{IID}: independent and identically distributed. The outcome
of one toss gives no information about the others, and all tosses
follow the same distribution.

Together, the population model and the sampling scheme describe the
\textbf{data generating process}: the mechanism that produces the
sequence of outcomes we observe.

Suppose we observe $65$ heads in our $100$ tosses. We use the observed
proportion of heads to estimate the unknown probability:
\[
  \widehat p=\frac{65}{100}=0.65.
\]
The hat means that $\widehat p$ is an estimate calculated from the
data. It does not mean that the true $p$ is exactly $0.65$; another
set of $100$ tosses could give a different proportion. Using data to
learn about an unknown model is called \textbf{inference}.

Now imagine that we choose the probability ourselves, for example
$p=0.5$, and ask the computer to produce $100$ independent tosses
with that probability. This is \textbf{simulation}: we specify the
model and the sampling scheme, then generate data following those
rules. We know the rules, but we do not fix the outcomes. One run
could give $48$ heads and another $53$.

\begin{notebox}[Inference and simulation]
\textbf{Inference.} We observe data and use them to learn about an
unknown model.
\[
  \text{Observed data}\ \longrightarrow\ \text{Information about the model}.
\]
\textbf{Simulation.} We choose a model and a sampling scheme, then
generate data from them.
\[
  \text{Specified model and sampling scheme}\ \longrightarrow\ \text{Simulated data}.
\]
For our coin, the simulation question is: what numbers of heads
could we observe in $100$ independent tosses if $p=0.5$?
Repeating the experiment on the computer lets us explore the
variation in those numbers.
\end{notebox}

\section{Where do the random numbers come from?}
\label{sec:random-number-generators}
We want the computer to simulate our $100$ coin tosses. A useful
starting point is a sequence of numbers that behave like independent
draws from a uniform distribution on $(0,1)$. But where do these
numbers come from?

\subsection{Using a physical source}
A \textbf{true random number generator} measures a physical source
of randomness, such as electronic noise or a quantum phenomenon.
The device processes those measurements to obtain numbers that a
computer can use. The changing patterns of lava lamps are another
example of a physical source.

We can distinguish two meanings of randomness:
\begin{itemize}
  \item \textbf{Epistemic randomness:} we cannot predict an outcome
    because we lack information about the process.
  \item \textbf{Ontological randomness:} randomness is intrinsic to
    the physical phenomenon itself.
\end{itemize}
For simulation, the practical idea is to obtain numbers from a
physical process. This requires a physical source and a device to
read it. Collecting and processing measurements can take time.
Repeating the experiment does not reproduce the same sequence of
outcomes, although we can save the numbers already collected.

\subsection{Using a formula}
There is another approach: choose an initial value $x_0$ and a
function $f$ that calculates the next value from the current one.
Apply the same function repeatedly. This is how a
\textbf{pseudorandom number generator} works.
\[
  \underbrace{x_0}_{\text{initial value}}
  \ \longrightarrow\ \underbrace{f(x_0)}_{x_1}
  \ \longrightarrow\ \underbrace{f(f(x_0))}_{x_2}
  \ \longrightarrow\ \underbrace{f(f(f(x_0)))}_{x_3}
  \ \longrightarrow\ \cdots
\]
First we calculate $x_1=f(x_0)$. We then use $x_1$ as the input
to the same function, obtaining $x_2=f(x_1)=f(f(x_0))$, and
continue in this way. In general, $x_{k+1}=f(x_k)$: each output
becomes the input for the next step. Here $f$ denotes the update rule.

The procedure is \textbf{deterministic}: once the starting value and
the rule are fixed, the entire sequence is determined. A suitable
generator is designed so that the sequence imitates the statistical
behaviour of random draws from the distribution we need.

The starting value is called the \textbf{seed}. Such generators can be fast
and require no additional physical device. To reproduce a run,
we can keep the seed and the generator settings rather than store
the whole sequence.

\begin{notebox}[Why the seed matters]
With the same generator, settings and seed, we obtain the same
sequence. This makes a simulation \textbf{reproducible}.

Imagine that a simulation gives an unexpected result. We can run it
again with the same seed and inspect exactly the same simulated
experiment. We can also compare two programs using the same inputs.

These pseudorandom numbers are the starting material from which
we generate simulated coin tosses, die rolls and observations from
other distributions.
\end{notebox}

\section{What should a pseudorandom sequence imitate?}
\label{sec:prng-uniform}
We can now make the goal of the generator more precise. We want
its output to imitate independent draws from a uniform distribution
on $(0,1)$.

\begin{frameddefn}{Pseudorandom number generator}
\label{def:prng}
In a simplified description, a \emph{pseudorandom number generator}
(PRNG) uses a deterministic function
\[
  f:(0,1)\longrightarrow(0,1)
\]
and a starting value, or \emph{seed}, $u_0\in(0,1)$ to generate
\[
  u_0,\quad u_1=f(u_0),\quad u_2=f(f(u_0)),\quad
  \ldots,\quad u_n=f^n(u_0).
\]
The function is chosen so that the sequence imitates the statistical
behaviour of an IID $\operatorname{Uniform}(0,1)$ sample.
Here $f^n(u_0)$ means applying $f$ repeatedly $n$ times.
\end{frameddefn}

There are two parts to this goal:
\begin{itemize}
  \item \textbf{Uniformity.} Intervals of the same length should
    receive approximately the same proportion of values. For example,
    in a sufficiently long sequence, about $10\%$ of the values
    should fall in $(0.2,0.3)$, and about $10\%$ in $(0.7,0.8)$.
  \item \textbf{Imitating independence.} The sequence should imitate
    draws in which observing one value gives no information about
    the others. We want to avoid systematic patterns between
    successive values.
\end{itemize}

For example, consider the repeating sequence
\[
  0.1,\ 0.2,\ 0.3,\ \ldots,\ 0.9,\ 0.1,\ 0.2,\ \ldots
\]
It visits different parts of the interval, but its next value is
easy to predict. Spreading values across the interval is only one
part of what we require from a good generator.

\begin{notebox}[The apparent paradox]
We know the seed and the rule, so the whole sequence is determined.
Yet we design the generator so that its output statistically
resembles independent uniform draws. Imitating an IID sample is
the goal; for a fixed seed, the generated sequence remains
deterministic.
\end{notebox}

\section{The linear congruential generator}
\label{sec:lcg}
A concrete way to generate the next value is to multiply the current
value, add a constant, and keep the remainder after division.

\begin{frameddefn}{Linear congruential generator}
\label{def:lcg}
A \emph{linear congruential generator} (LCG) uses integer parameters
$\alpha$, $\beta$, and $M>1$, and an integer seed
$x_0\in\{0,1,\ldots,M-1\}$. Its update rule is
\[
  x_{k+1}=f(x_k)=(\alpha+\beta x_k)\bmod M.
\]
Here $\bmod M$ gives the remainder after division by $M$, so every
state $x_k$ belongs to $\{0,1,\ldots,M-1\}$.
\end{frameddefn}

At each step, we multiply the current value by $\beta$, add $\alpha$,
and take the remainder. The resulting integer becomes the input
for the next step.

\Needspace{25\baselineskip}
\begin{framedexample}{Following the sequence and finding its period}
Choose small parameters so that we can follow the calculations:
\[
  \alpha=1,\qquad \beta=5,\qquad M=16,\qquad x_0=2.
\]
The first three updates are
\[
  \begin{aligned}
    x_1&=(1+5\cdot2)\bmod16=11,\\
    x_2&=(1+5\cdot11)\bmod16=56\bmod16=8,\\
    x_3&=(1+5\cdot8)\bmod16=41\bmod16=9.
  \end{aligned}
\]
For example, $56=3\cdot16+8$, so its remainder is $8$.
Continuing with the same rule gives
\[
  \begin{aligned}
    2&\to11\to8\to9\to14\to7\to4\to5\\
     &\to10\to3\to0\to1\to6\to15\to12\to13\to2.
  \end{aligned}
\]
Once $2$ returns, the same rule produces $11$ again, then $8$, and
so on: the sequence repeats. The \textbf{period} is the length of
this repeating cycle.

Here we visit all $16$ possible states before returning to the
starting value. The period is therefore $16$, the maximum possible
for $M=16$. In general, an LCG can have period $M$ with appropriate
choices of its parameters.
\end{framedexample}

To rescale the integer states to numbers between $0$ and $1$, we can
use
\[
  u_k=\frac{x_k}{M+1}.
\]
For the first three generated states in the example, this gives
\[
  \frac{11}{17}\approx0.647,\qquad
  \frac8{17}\approx0.471,\qquad
  \frac9{17}\approx0.529.
\]
The output can be $0$ when the remainder is $0$, and is always less
than $1$. Rescaling changes the range of the values; the parameters
determine how the sequence behaves statistically.

\begin{notebox}[Why the choice of parameters matters]
We want the sequence to avoid repeating too soon. If we instead
choose $\beta=2$, keeping $\alpha=1$, $M=16$ and $x_0=2$, we get
\[
  2\to5\to11\to7\to15\to15\to15\to\cdots
\]
The generator gets stuck at $15$, so the repeating cycle has period
$1$. Such a sequence would be unsuitable for simulating coin tosses.

A long period is one requirement for a useful generator. We also
need its output to imitate uniformity and independence. Our small
example illustrates the calculations and a full cycle; assessing
statistical quality requires more than checking the period.
\end{notebox}

\section{The LCG in R}
\label{sec:lcg-r}
We can translate the update rule into a short R function. To follow
the calculations, we keep the small parameters from
\hyperref[sec:lcg]{the previous example} and generate three values:
\begin{lstlisting}[language=R]
lcg <- function(n = 3, a = 1, b = 5, M = 16, u0 = 2) {
  # Map an integer seed to a valid state between 0 and M - 1.
  u0 <- u0 %% M
  out <- rep(NA, n)

  for (i in 1:n) {
    u0 <- (a + b*u0) %% M
    out[i] <- u0 / (M + 1)
  }

  return(out)
}
\end{lstlisting}
Here \texttt{a} corresponds to $\alpha$, \texttt{b} to $\beta$, and
\texttt{n} is the number of values we ask the function to produce.
The argument \texttt{u0} supplies the initial seed.

\Needspace{15\baselineskip}
\subsection{Checking uniformity with a histogram}
A \textbf{histogram} shows how numerical values are spread across
intervals. We divide the range into intervals, count the values in
each one, and draw adjacent bars. For equal widths, taller bars
mean more values: we can see where the values are concentrated.

We use the same function to generate $1000$ values, with seed $26$ and parameters
$a=69069069$, $b=12345$ and $M=4096$:
\begin{lstlisting}[language=R]
u <- lcg(n = 1000, a = 69069069, b = 12345,
         M = 2^12, u0 = 26)
hist(u, breaks = seq(0, 1, 0.1), probability = TRUE)
abline(h = 1, lty = 2)
\end{lstlisting}
We use ten intervals of width $0.1$. Here $80$ values fall between
$0$ and $0.1$, and $107$ between $0.1$ and $0.2$, so the first bar
is lower than the second. For a uniform distribution on $(0,1)$,
each interval has probability $0.1$: we would expect about $100$
values per interval in a sample of size $1000$.

\begin{center}
  \includegraphics[width=0.78\linewidth]{assets/lcg-uniformity-histogram.png}
\end{center}

With \texttt{probability = TRUE}, the vertical axis shows density.
Each bar's height is its count divided by the product of the sample
size and the interval width.
For $100$ values in an interval of width $0.1$, the height is
$100/(1000\times0.1)=1$. Each bar's area is the fraction of values
in its interval; the total area is $1$.

The dashed line is the uniform density, $1$ on $(0,1)$. The bars
are roughly close to it: a first visual check of uniformity.
Their heights need not be identical in a finite sequence.
A histogram does not check independence: rearranging the values
leaves it unchanged.

\section{Assessing the quality of a generator}
\label{sec:prng-quality}
We have seen how a generator produces numbers. We now ask whether
those numbers behave well enough for our simulations.

Software uses generators more sophisticated than the LCG;
the \textbf{Mersenne Twister} is one example. No pseudorandom
generator produces a perfect IID sample: its sequence is determined
by its initial state and update rule. Nevertheless, suitable
generators can imitate independent uniform draws well enough for
many practical purposes.

\Needspace{14\baselineskip}
We assess three \textbf{properties} of the output, understood as
criteria for judging the quality of the generator:
\begin{itemize}
  \item \textbf{Property 0: Period.} The sequence should have a period
    long enough for the simulation. We examined this in
    \hyperref[sec:lcg]{the LCG example}.
  \item \textbf{Property 1: Distribution of samples.} The values
    should imitate draws from a uniform distribution on $(0,1)$.
    The histogram provides a first visual check.
  \item \textbf{Property 2: Independence of samples.} Groups of
    values should imitate independent draws, without systematic
    patterns between successive outputs.
\end{itemize}
Producing numbers between $0$ and $1$ is only the starting point;
these properties concern the behaviour of the sequence as a whole.

\begin{octoberreview}
\subsection{Checking consecutive pairs}
A histogram ignores the order of the values. To look for dependence,
form the pairs
\[
  (u_1,u_2),\ (u_2,u_3),\ldots,(u_{n-1},u_n)
\]
and draw a scatter plot. Using the sequence \texttt{u} generated
above, with at least two values:
\begin{lstlisting}[language=R]
n <- length(u)
plot(u[-n], u[-1], pch = ".",
     xlab = "Current value", ylab = "Next value")
\end{lstlisting}
Here \texttt{u[-n]} removes the last value, while \texttt{u[-1]}
removes the first, so the vectors contain matching consecutive pairs.
Lines, bands, or other systematic patterns reveal structure that
the histogram may miss. A scatter without an obvious pattern is
a visual diagnostic, not a proof of independence.
\end{octoberreview}

\Needspace{10\baselineskip}
\begin{notebox}[For further reading]
To prove when the LCG $x_{k+1}=(\alpha+\beta x_k)\bmod M$ has
period $M$, we need to establish four points:
\begin{enumerate}
  \item \textbf{First necessary condition.} Show that period $M$
    requires $\gcd(\alpha,M)=1$.
  \item \textbf{Second necessary condition.} Show that period $M$
    requires $\beta-1$ to be divisible by every prime factor of $M$.
  \item \textbf{Third necessary condition.} Show that, if $4$ divides
    $M$, period $M$ requires $4$ to divide $\beta-1$.
  \item \textbf{Sufficiency.} Show that the three conditions together
    guarantee period $M$ for every seed
    $x_0\in\{0,1,\ldots,M-1\}$.
\end{enumerate}
Original reference:
\href{https://epubs.siam.org/doi/10.1137/1004061}{Hull and Dobell,
\textit{Random Number Generators} (1962)}.
\end{notebox}

\section{The quantile transform method}
\label{sec:quantile-transform}
We now have a way to generate numbers that imitate independent
uniform draws. How can we use them to simulate a different
distribution? The link is the
\hyperref[def:quantile-general]{quantile function}.

\begin{framedexample}{From uniform numbers to a biased coin}
\label{ex:quantile-transform-bridge}
\textbf{1. The goal.} We want to simulate a coin whose result is
$0$ with probability $0.6$ and $1$ with probability $0.4$.
Let $X$ denote the desired coin result:
\[
  P(X=0)=0.6,\qquad P(X=1)=0.4.
\]
Each simulated toss must return one of these two values.

\textbf{2. Start with a uniform number.} The computer generates
$U\sim\operatorname{Unif}(0,1)$. Split the unit interval into a
part of length $0.6$ and a part of length $0.4$, and return
\[
  Y=
  \begin{cases}
    0, & U\leq0.6,\\
    1, & U>0.6.
  \end{cases}
\]
For example, $u=0.25$ gives $y=0$, whereas $u=0.82$ gives $y=1$.
Since $U$ is uniform, the first part is selected with probability
$0.6$ and the second with probability $0.4$. The generated result
$Y$ therefore has the probabilities we wanted.

\textbf{3. Recognize the quantile rule.} The desired CDF satisfies
\[
  F(0)=P(X\leq0)=0.6,\qquad F(1)=P(X\leq1)=1.
\]
The quantile $Q(p)$ returns the smallest value whose CDF reaches
or exceeds the input probability level $p$.
For $p=0.82$, the value $0$ does not qualify because
$F(0)=0.6<0.82$, while $1$ does because $F(1)=1\geq0.82$.
Hence $Q(0.82)=1$. For $p=0.50$, the value $0$ already qualifies
because $F(0)=0.6\geq0.50$, so $Q(0.50)=0$.

\textbf{4. The bridge.} The input $u$ is a probability level;
the output $Q(u)$ is a possible value of the coin, $0$ or $1$.
Using a randomly generated uniform number as that input gives
$Y=Q(U)$. This turns uniform draws into draws from the desired
distribution.
\end{framedexample}

\clearpage
Previously, we chose a probability level $p$ and found the
corresponding threshold $Q(p)$. Now we draw that level at random:
we generate $U$ uniformly between $0$ and $1$ and return $Q(U)$.
This is the \textbf{quantile transform method}, also called the
\textbf{inverse transform method}.

\begin{framedprop}{Quantile transform}
\label{prop:quantile-transform}
Let $F$ be any CDF and let
\[
  Q(p)=\inf\{x\in\mathbb R:F(x)\geq p\},\qquad 0<p<1,
\]
be its quantile function. If $U\sim\operatorname{Unif}(0,1)$ and
$Y=Q(U)$, then $Y$ has CDF $F$:
\[
  F_Y(y)=P(Y\leq y)=F(y),\qquad y\in\mathbb R.
\]
\end{framedprop}

\textbf{Proof in the continuous, strictly increasing case.}
In this case $Q=F^{-1}$. Since $F$ is increasing,
$F^{-1}(U)\leq y$ is equivalent to $U\leq F(y)$. Therefore,
\begin{align*}
  F_Y(y)&=P(Y\leq y)\\
        &=P\bigl(F^{-1}(U)\leq y\bigr)\\
        &=P\bigl(U\leq F(y)\bigr)\\
        &=F(y).
\end{align*}
The last step uses the
\hyperref[sec:uniform-standard]{standard uniform distribution's CDF}:
$P(U\leq t)=t$ for $0\leq t\leq1$. Here the threshold is
$t=F(y)$, which lies in $[0,1]$ because $F$ is a CDF.
Thus the generated variable has exactly the CDF we wanted.
The result also holds for CDFs with jumps or flat parts, using the
general quantile definition; the proof above covers the invertible
case.

To generate a sample, draw independent $U_1,\ldots,U_n$ and set
$Y_i=Q(U_i)$ for each $i$. Applying the same function separately
to independent draws preserves independence, and every $Y_i$ has
CDF $F$.

\subsection{A continuous example}
\begin{framedexample}{Generating values with density $3x^2$}
Suppose we want to simulate a variable $X$ with PDF
\[
  f_X(x)=
  \begin{cases}
    3x^2, & 0\leq x\leq1,\\
    0, & \text{otherwise}.
  \end{cases}
\]
\textbf{Find the CDF.} For $0\leq x<1$,
\[
  F_X(x)=\int_0^x3t^2\,dt=[t^3]_0^x=x^3.
\]
The complete CDF is
\[
  F_X(x)=
  \begin{cases}
    0, & x<0,\\
    x^3, & 0\leq x<1,\\
    1, & x\geq1.
  \end{cases}
\]
\textbf{Find the quantile.} For $0<p<1$, solve $x^3=p$:
\[
  Q(p)=p^{1/3}.
\]
\textbf{Generate a value.} Draw $U\sim\operatorname{Unif}(0,1)$
and return
\[
  \boxed{Y=U^{1/3}.}
\]
For example, the uniform value $u=0.125$ becomes
$y=0.125^{1/3}=0.5$.

\section{From generator checks to statistical learning}
\label{sec:loss-risk-density}

The blackboard discussion on 2 October turned the visual
histogram check into a more general question: how can we measure
the difference between a target density and an estimate obtained
from data?

\subsection{A target density and a histogram estimate}
For the standard uniform distribution, the target is known:
\[
  f_U(u)=\mathbf 1_{[0,1]}(u).
\]
Let $u_1,\ldots,u_n$ be the available values. A density histogram
with equal bin width $h$ gives an estimate
$\widehat f_{n,h}$. If bin $B_j$ contains $N_j$ observations,
its height is
\[
  \widehat f_{n,h}(u)=\frac{N_j}{nh},\qquad u\in B_j.
\]
Use disjoint bins covering the range, assigning a boundary point
to just one bin. Each bin's area is $N_j/n$, so the histogram
has total area $1$.

The notation records two choices: $n$ is the sample size and
$h$ is the bin width. The histogram is an algorithm that turns
the data into a density estimate.

\subsection{Distances between densities}
The lecture introduced the following ways to compare densities
$f$ and $g$:
\begin{align*}
  D_1(f,g)&=\int_{\mathbb R}|f(u)-g(u)|\,du,\\[3pt]
  D_2(f,g)&=\left(\int_{\mathbb R}|f(u)-g(u)|^2\,du\right)^{1/2},\\[3pt]
  D_\infty(f,g)&=\operatorname*{ess\,sup}_{u\in\mathbb R}
    |f(u)-g(u)|.
\end{align*}
These are the $L^1$, $L^2$, and $L^\infty$ distances, when finite.
The first accumulates absolute discrepancies; the second
squares them before integration; the third looks at the largest
discrepancy, ignoring changes on sets of length zero.

More generally, for $1\leq q<\infty$,
\[
  D_q(f,g)=\left(\int_{\mathbb R}|f(u)-g(u)|^q\,du\right)^{1/q}.
\]
Different distances emphasize different features of the error.

\clearpage
\subsection{Loss for one dataset and average risk}
Once the data are fixed, the discrepancy
\[
  \ell_n(u_1,\ldots,u_n)
    =D\bigl(f_U,\widehat f_{n,h}\bigr)
\]
is the \textbf{loss} for that dataset. A different dataset may
produce a different histogram and a different loss.

The blackboard contrasted two possible goals:
\begin{itemize}
  \item \textbf{Worst-case loss:} control the largest loss over
    the possible datasets. In schematic form,
    \[
      \sup_{\mathbf u\in[0,1]^n}\ell_n(\mathbf u)
        \longrightarrow0.
    \]
  \item \textbf{Average loss:} average over datasets generated
    by a specified sampling model. This average is the
    \textbf{risk}:
    \[
      R_n(f_U;h)=
        \mathbb E_{f_U}\!\left[
          D\bigl(f_U,\widehat f_{n,h}\bigr)\right].
    \]
\end{itemize}
For example, under ideal independent uniform sampling, the
expectation averages over the random samples
$(U_1,\ldots,U_n)$. Risk tending to zero is an average guarantee;
it does not require small loss for every possible dataset.

The worst-case requirement is much stronger. For an ordinary
histogram it need not hold: datasets concentrated in one bin
remain possible even when the target distribution is uniform.

\begin{notebox}[A criterion is not an LCG convergence theorem]
These formulas express ways to judge an estimation procedure.
They do not prove that every LCG converges to a uniform density.
With a fixed seed, an LCG produces a deterministic sequence;
an average risk requires a stated source of randomness, such as
a random seed or a sampling model. Results for ideal IID data
do not automatically apply to a deterministic generator.
\end{notebox}

\clearpage
\subsection{Unknown ground truth and a class of models}
In the simulation check, $f_U$ is known. In a learning problem,
the true population density $f$ is typically unknown, and the
algorithm must estimate it from data.

For data generated from $f$, define
\[
  R_n(f;h)=\mathbb E_f\!\left[
    D\bigl(f,\widehat f_{n,h}\bigr)\right].
\]
The subscript $f$ records the distribution used to average over
datasets. The lecture's phrase ``all ground truths that make
sense'' refers to a specified class of possible densities
$\mathcal F$.

There are two distinct consistency requirements:
\begin{itemize}
  \item \textbf{For a fixed density:}
    $R_n(f;h_n)\to0$ for that population density $f$.
  \item \textbf{Uniformly over a class:}
    \[
      \sup_{f\in\mathcal F}R_n(f;h_n)\longrightarrow0.
    \]
\end{itemize}
In the second expression, we first average over datasets for
each $f$, then take the worst risk over the class of population
densities. This supremum is over \emph{models}, whereas the
earlier worst-case loss was over \emph{datasets}.

The class $\mathcal F$ and the estimation procedure matter.
The formula is a goal to establish under suitable assumptions,
not a guarantee for every class of densities. Writing $h_n$
allows the bin width to change with sample size; a fixed bin
width may retain approximation error for a general density.

\subsection{Qualitative and quantitative questions}
The final board remarks distinguish:
\begin{itemize}
  \item \textbf{Qualitative:} does the risk tend to zero?
    This is a consistency question.
  \item \textbf{Quantitative:} how fast does it tend to zero
    as the sample size grows? This asks for a convergence rate.
\end{itemize}
A rate may be expressed by a bound such as
\[
  \sup_{f\in\mathcal F}R_n(f;h_n)\leq C r_n,
  \qquad r_n\longrightarrow0,
\]
where $C$ does not depend on $n$. Such a bound must be proved
for the chosen model class, loss, and algorithm; the board
discussion did not establish a specific rate for the LCG.
\end{octoberreview}

\section{Transformations of random variables}
\label{chap:random-variable-transformations}

\begin{tcolorbox}[colback=yellow!20,colframe=yellow!60!black,
  boxrule=0.4pt,arc=1mm,left=5pt,right=5pt,top=3pt,bottom=3pt,
  before skip=6pt,after skip=6pt]
\small\textbf{Start of lecture 8 October}
\end{tcolorbox}

\subsection{What are we trying to compute?}

Suppose we know the distribution of a random variable $X$ and
apply a deterministic function $r$ to its value. This defines
a new random variable
\[
  Y=r(X).
\]
The function $r$ tells us how to transform each value. We want
to find the \textbf{distribution of the resulting values}:
the CDF $F_Y$ and, when it exists, the PDF $f_Y$.

In the \hyperref[sec:quantile-transform]{quantile transform method},
we chose $r=Q$ to obtain a desired distribution from uniform
draws. Here we study what distribution a given transformation
produces.

\begin{framedexample}{Squaring a uniform random variable}
\label{ex:square-uniform}
Let $X\sim\operatorname{Unif}(-1,1)$ and define $Y=X^2$.
The PDF of $X$, from
\hyperref[sec:uniform-distribution]{Section~\ref{sec:uniform-distribution}}, is
\[
  f_X(x)=\frac12\mathbf 1_{[-1,1]}(x).
\]
For example, $X=-0.5$ gives $Y=0.25$, and $X=0.5$ gives the
same result. Squaring loses the sign of the input.

Since $-1\leq X\leq1$, we have $0\leq Y\leq1$.
Every value in $[0,1]$ can be obtained by squaring a value in
$[-1,1]$, so the output range is $[0,1]$.
Knowing this range alone does not tell us how probability
is distributed within it.
\end{framedexample}

\clearpage
\subsection{Find probabilities first, then the CDF}
\label{sec:square-uniform-cdf}

First calculate one interval probability, then let the threshold
vary to obtain the full CDF.

\subsubsection{Start with a concrete threshold}
\label{sec:square-uniform-concrete-threshold}
For the example above, consider the probability that the
\emph{transformed} value is at most $0.25$:
\[
  P(Y\leq0.25).
\]
To compute it, find which \emph{input} values produce such an
output. Because $Y=X^2$,
\[
  Y\leq0.25
  \quad\Longleftrightarrow\quad
  X^2\leq0.25
  \quad\Longleftrightarrow\quad
  -0.5\leq X\leq0.5.
\]
Both negative and positive input values must be included.
The selected interval has length $1$, while the support
$[-1,1]$ has length $2$. Uniformity of $X$ therefore gives
\[
  P(Y\leq0.25)=P(-0.5\leq X\leq0.5)=\frac12.
\]
Thus half the probability of $Y$ lies in the first quarter
of its range. If $Y$ were uniform on $[0,1]$, that probability
would be $0.25$. \textbf{The transformed variable is not uniform.}

\subsubsection{Replace the threshold by a general value}
The CDF asks the same question for every threshold $y$:
\[
  F_Y(y)=P(Y\leq y).
\]
For $0\leq y\leq1$, solving $X^2\leq y$ gives
$-\sqrt y\leq X\leq\sqrt y$. Hence
\begin{align*}
  F_Y(y)
    &=P(-\sqrt y\leq X\leq\sqrt y)\\
    &=\int_{-\sqrt y}^{\sqrt y}\frac12\,dx
      =\frac{\sqrt y-(-\sqrt y)}{2}=\sqrt y.
\end{align*}
Including thresholds outside the support gives the complete CDF:
\[
  F_Y(y)=
  \begin{cases}
    0, & y<0,\\
    \sqrt y, & 0\leq y\leq1,\\
    1, & y>1.
  \end{cases}
\]
As a check, $F_Y(0.25)=\sqrt{0.25}=0.5$, agreeing with the
concrete calculation. This is a cumulative probability, not a
PDF value.

\clearpage
\subsection{From the CDF of Y to the PDF of Y}
\label{sec:square-uniform-pdf}

For a variable with a PDF, the CDF accumulates area under
the PDF:
\[
  F_Y(y)=\int_{-\infty}^{y}f_Y(t)\,dt.
\]
Differentiation recovers the PDF from this accumulated area.
For our example, on the interior of the output range,
\[
  f_Y(y)=\frac{d}{dy}F_Y(y)
    =\frac{d}{dy}\sqrt y=\frac{1}{2\sqrt y},
  \qquad 0<y<1.
\]
A complete version of the PDF is
\[
  f_Y(y)=
  \begin{cases}
    \displaystyle\frac{1}{2\sqrt y}, & 0<y<1,\\[5pt]
    0, & \text{otherwise}.
  \end{cases}
\]
For a continuous random variable with a PDF, probabilities are
areas under the PDF. A single point has zero width, so changing
the value of the PDF only at $y=0$ or $y=1$ does not change any
area or probability.

The formula $1/(2\sqrt y)$ is undefined at $y=0$, because it would
require division by zero. We choose $f_Y(0)=0$ to complete the
definition. This is the value at the exact point $0$. For positive
values of $y$ closer and closer to $0$, the formula gives larger
and larger PDF values, without any upper bound.

  \includegraphics[width=0.78\linewidth]{assets/square-uniform-density.png}
\end{center}

\Needspace{10\baselineskip}
\subsubsection{Why is the PDF high near zero?}
Squaring brings values with absolute value below $1$ closer to
zero, and both signs contribute to the same output values.
The calculation $P(0\leq Y\leq0.25)=0.5$ shows the resulting
concentration near zero.

The high PDF is not a positive probability at the point
$0$: $P(Y=0)=P(X=0)=0$.

\medskip
Interval probabilities are areas under the PDF. For $0\leq a<b\leq1$,
\[
  P(a\leq Y\leq b)=F_Y(b)-F_Y(a)=\sqrt b-\sqrt a.
\]
For example,
\[
  P(0.25\leq Y\leq1)=1-0.5=0.5.
\]
Compare the two intervals:
\begin{itemize}
  \item \hyperref[sec:square-uniform-concrete-threshold]{$[0,0.25]$ has length $0.25$ and contains probability $0.5$}.
  \item $[0.25,1]$ has length $0.75$ and also contains probability $0.5$.
\end{itemize}

The same amount of probability
is therefore collected in a shorter interval near zero.
This shows that the probability of $Y$ is more concentrated
near zero.

The PDF grows without bound near zero. Could its total area
therefore be infinite? As we know, the total area should be $1$,
as required for a PDF. The height of the curve alone does not
determine its area: we must calculate the integral.

To handle the unbounded PDF near zero, start at a positive
number $\varepsilon$:
\[
  \int_{\varepsilon}^{1}\frac{1}{2\sqrt y}\,dy
    =\bigl[\sqrt y\bigr]_{\varepsilon}^{1}
    =1-\sqrt{\varepsilon}.
\]
Then let $\varepsilon$ approach zero from the right, including
more and more of the area near zero:
\[
  \int_0^1\frac{1}{2\sqrt y}\,dy
    =\lim_{\varepsilon\downarrow0}(1-\sqrt{\varepsilon})=1.
\]
Thus the PDF grows without bound near zero, but its total area
is finite and equals $1$.

\subsection{The general method: transform the event}
\label{sec:general-transformation}

We now generalize the procedure used in the example $Y=X^2$
so that we can apply it to any transformation $Y=r(X)$.
We start from the known PDF of $X$ and want to find the CDF
of $Y$ and, when it exists, its PDF.

The procedure follows three steps. Suppose $X$
has a PDF $f_X$, support $S_X$, and $Y=r(X)$.

\begin{enumerate}
  \item \textbf{Find the input values selected by a threshold.}
    For a fixed $y$, solve the inequality $r(x)\leq y$ on
    the support of $X$. Write its solution set as
    \[
      A_y=\{x\in S_X:r(x)\leq y\}.
    \]
    The subscript records that this set changes when the
    threshold $y$ changes.
  \item \textbf{Compute the CDF using the input distribution.}
    The events $\{Y\leq y\}$ and $\{X\in A_y\}$ are the same,
    so
    \[
      F_Y(y)=P(r(X)\leq y)=P(X\in A_y)
        =\int_{A_y}f_X(x)\,dx.
    \]
    We integrate the known PDF of $X$ over the selected
    input values to obtain a probability about $Y$.
  \item \textbf{Obtain a PDF when one exists.}
    If the CDF can be written as an integral of a PDF,
    differentiate it to recover $f_Y(y)=F_Y'(y)$ wherever
    the derivative exists.
\end{enumerate}

\begin{notebox}
This method does not require $r$ to be invertible.
\end{notebox}

\begin{notebox}
Even if $X$ has a PDF, its transformation $Y$ may not have one.

For example, let $X\sim\operatorname{Unif}(-1,1)$ and choose
$r(x)=0$. Every input value gives $Y=0$, so $P(Y=0)=1$.

If $Y$ had a PDF, we would instead have
\[
  P(Y=0)=P(0\leq Y\leq0)=\int_0^0 f_Y(t)\,dt=0.
\]
An integral with identical lower and upper limits is zero.
This contradicts $P(Y=0)=1$, so $Y$ has no PDF.
Its PMF assigns $p_Y(0)=1$.
The event method still gives its CDF: $F_Y(y)=0$ for $y<0$
and $F_Y(y)=1$ for $y\geq0$.
\end{notebox}

\clearpage
\subsection{When the transformation has an inverse}
\label{sec:invertible-transformation}

Slide 5 gives a shortcut when $r$ is strictly monotone on the
input support. Let $s=r^{-1}$ denote its inverse.
For thresholds inside the output range, the direction of
monotonicity determines the CDF calculation.

\textbf{If $r$ is increasing}, applying the inverse preserves
the inequality:
\[
  F_Y(y)=P(r(X)\leq y)=P(X\leq s(y))=F_X(s(y)).
\]
\textbf{If $r$ is decreasing}, applying the inverse reverses it:
\[
  F_Y(y)=P(X\geq s(y))=1-F_X(s(y)),
\]
where we used continuity of $X$, so $P(X=s(y))=0$.
The CDF expression written on the slide is the increasing case.

Under the usual smoothness assumptions (for example, $r$ is
continuously differentiable with nonzero derivative on the
interior of the support), the two cases give the PDF formula
\[
  f_Y(y)=f_X(s(y))\,|s'(y)|.
\]
The factor $|s'(y)|$ accounts for the change in interval lengths.
This single-inverse formula cannot be applied directly to
$x^2$ on the full interval $[-1,1]$.

\subsubsection{The connection with the quantile transform}
For the square example, $F_Y(y)=\sqrt y$ on $[0,1]$ is
strictly increasing. Solving $p=\sqrt y$ for $y$ gives
\[
  Q_Y(p)=p^2,\qquad 0<p<1.
\]
For example, $Q_Y(0.5)=0.25$, the threshold containing half
the probability below it.

Thus the \hyperref[prop:quantile-transform]{quantile transform}
offers another way to generate this distribution:
draw $U\sim\operatorname{Unif}(0,1)$ and return $Q_Y(U)=U^2$.
Both $X^2$ with $X\sim\operatorname{Unif}(-1,1)$ and $U^2$
with $U\sim\operatorname{Unif}(0,1)$ have the CDF $\sqrt y$
on $[0,1]$.

\begin{framedexercise}{Computer virus}
A virus can enter a computer through e-mail or the internet. The
probability of entry through e-mail is $0.30$, through the internet
$0.40$, and through both routes $0.15$. What is the probability that
the virus does not enter at all?
\end{framedexercise}

\solutionheading{Solution.}
Let
\[
  E=\{\text{the virus enters through e-mail}\},\qquad
  I=\{\text{the virus enters through the internet}\}.
\]
\begin{enumerate}[label=\textbf{Step \arabic*:},leftmargin=*]
  \item \textbf{Define the target event.} Let $N=E^c\cap I^c$ be the
  event that the virus does not enter. We seek $P(N)$.
  \item \textbf{Apply De Morgan's law.}
  \[
    P(N)=P\bigl((E\cup I)^c\bigr).
  \]
  \item \textbf{Use the complement rule.}
  \[
    P\bigl((E\cup I)^c\bigr)=1-P(E\cup I).
  \]
  \item \textbf{Calculate the union by inclusion--exclusion.}
  \[
    P(E\cup I)=P(E)+P(I)-P(E\cap I)
      =0.30+0.40-0.15=0.55.
  \]
  \item \textbf{Take the complement.}
  \[
    \boxed{P(N)=1-0.55=0.45=45\%.}
  \]
\end{enumerate}

\begin{framedexercise}{Two children}
A family has two children, and at least one is a boy. What is the
probability that both are boys?
\end{framedexercise}

\solutionheading{Solution.}
Assume each child is independently a boy or a girl with probability
$1/2$. Let
\[
  B_1=\{\text{the first child is a boy}\},\qquad
  B_2=\{\text{the second child is a boy}\}.
\]
\begin{enumerate}[label=\textbf{Step \arabic*:},leftmargin=*]
  \item \textbf{Define the events in the question.} Let
  \begin{align*}
    A&=B_1\cap B_2
       =\{\text{both children are boys}\},\\
    C&=B_1\cup B_2
       =\{\text{at least one child is a boy}\}.
  \end{align*}
  We seek $P(A\mid C)$.
  \item \textbf{List the ordered outcomes.} With $B$ for boy and $G$
  for girl, the equally likely possibilities are
  \[
    \Omega=\{BB,BG,GB,GG\}.
  \]
  \item \textbf{Use the information given.} The event $C$ excludes
  $GG$, leaving
  \[
    C=\{BB,BG,GB\}.
  \]
  \item \textbf{Count the favorable outcomes.} We have $A=\{BB\}$,
  so one of the three outcomes in $C$ is favorable:
  \[
    \boxed{P(A\mid C)=\frac13.}
  \]
\end{enumerate}

\exerciseheading{Check using conditional probability.}
Since $A\subseteq C$, we have $A\cap C=A$. Independence and the
complement rule give
\[
  P(A)=\frac12\cdot\frac12=\frac14,
  \qquad
  P(C)=1-P(\{GG\})=1-\frac14=\frac34.
\]
Therefore
\[
  P(A\mid C)=\frac{P(A\cap C)}{P(C)}
             =\frac{1/4}{3/4}=\frac13.
\]
If the information had instead been \emph{the first child is a boy},
only $BB$ and $BG$ would remain, giving $1/2$. The way the information
is supplied matters.

\begin{framedexercise}{Rolling two dice}
Two fair six-sided dice are rolled. Describe the sample space and
find the probability that their sum is seven.
\end{framedexercise}

\solutionheading{Solution.}
\begin{enumerate}[label=\textbf{Step \arabic*:},leftmargin=*]
  \item \textbf{Write the sample space.} The result is an ordered pair
  $(i,j)$, one value for each die:
  \[
    \Omega=\{(i,j):i,j\in\{1,\ldots,6\}\},
    \qquad |\Omega|=6\cdot6=36.
  \]
  In particular, $(1,6)$ and $(6,1)$ are different outcomes.
  \item \textbf{Define the target event.} Let
  \[
    S=\{(i,j)\in\Omega:i+j=7\}
     =\{(1,6),(2,5),(3,4),(4,3),(5,2),(6,1)\}.
  \]
  We seek $P(S)$, and $|S|=6$.
  \item \textbf{Apply the equally likely outcomes rule.}
  \[
    \boxed{P(S)=\frac{|S|}{|\Omega|}=\frac{6}{36}=\frac16.}
  \]
\end{enumerate}

\begin{framedexercise}{Five-card poker hands}
Assume that all five-card hands from a standard $52$-card deck are
equally likely. Find the probabilities of a flush (five cards of
one suit), four of a kind, and exactly one pair.
\end{framedexercise}

\solutionheading{Solution.}
Because order does not matter, all three probabilities have the same
denominator:
\[
  N=\binom{52}{5}=2\,598\,960.
\]

\exerciseheading{Flush.}
\begin{enumerate}[label=\textbf{Step \arabic*:},leftmargin=*]
  \item \textbf{Choose the suit:} $4$ possibilities.
  \item \textbf{Choose five cards of that suit:} $\binom{13}{5}$
  possibilities.
  \item \textbf{Count and divide:}
  \[
    \boxed{P(\text{flush})
      =\frac{4\binom{13}{5}}{N}
      =\frac{5\,148}{2\,598\,960}
      \approx 0.001981.}
  \]
\end{enumerate}
Under the exercise's definition, this includes straight flushes.

\exerciseheading{Four of a kind.}
\begin{enumerate}[label=\textbf{Step \arabic*:},leftmargin=*]
  \item \textbf{Choose the rank:} $13$ possibilities. All four cards
  of that rank are then fixed.
  \item \textbf{Choose the fifth card:} any of the remaining $48$.
  \item \textbf{Count and divide:}
  \[
    \boxed{P(\text{four of a kind})
      =\frac{13\cdot48}{N}
      =\frac{624}{2\,598\,960}
      \approx 0.0002401.}
  \]
\end{enumerate}

\exerciseheading{Exactly one pair.}
\begin{enumerate}[label=\textbf{Step \arabic*:},leftmargin=*]
  \item \textbf{Choose the pair's rank:} $13$ possibilities.
  \item \textbf{Choose its two suits:} $\binom42$ possibilities.
  \item \textbf{Choose the other three ranks:} $\binom{12}{3}$ ways.
  They must be distinct, avoiding another pair or a triple.
  \item \textbf{Choose their suits:} $4^3$ possibilities.
  \item \textbf{Count and divide:}
  \[
    \boxed{P(\text{exactly one pair})
      =\frac{13\binom42\binom{12}{3}4^3}{N}
      =\frac{1\,098\,240}{2\,598\,960}
      \approx 0.42257.}
  \]
\end{enumerate}

\begin{framedexercise}{Rome and Florence}
The probability that a tourist has visited Rome is $26\%$, the
probability that they have visited Florence is $18\%$, and the
probability that they have visited at least one of the two cities is
$38\%$.

\textbf{Question A.} What is the probability that the tourist has visited
both Rome and Florence?

\textbf{Question B.} What is the probability that the tourist has visited
Rome but not Florence?
\end{framedexercise}

\exerciseheading{Notation.}
Let
\[
  R=\{\text{the tourist has visited Rome}\},\qquad
  F=\{\text{the tourist has visited Florence}\}.
\]
The given probabilities are
\[
  P(R)=0.26,\qquad P(F)=0.18,\qquad P(R\cup F)=0.38.
\]

\solutionheading{Solution to A.}
\begin{enumerate}[label=\textbf{Step \arabic*:},leftmargin=*]
  \item \textbf{Define the target event.} Let
  \[
    A=R\cap F=\{\text{the tourist has visited both cities}\}.
  \]
  We seek $P(A)$.
  \item \textbf{Apply inclusion--exclusion and substitute.}
  \begin{align*}
    P(A)
      &=P(R)+P(F)-P(R\cup F)\\
      &=0.26+0.18-0.38\\
      &=\boxed{0.06=6\%}.
  \end{align*}
\end{enumerate}

\solutionheading{Solution to B.}
\begin{enumerate}[label=\textbf{Step \arabic*:},leftmargin=*]
  \item \textbf{Define the target event.} Let
  \[
    B=R\cap F^c
      =\{\text{the tourist has visited Rome but not Florence}\}.
  \]
  We seek $P(B)$.
  \item \textbf{Subtract the overlap from Rome.}
  \begin{align*}
    P(B)
      &=P(R)-P(A)\\
      &=0.26-0.06\\
      &=\boxed{0.20=20\%}.
  \end{align*}
\end{enumerate}

\begin{framedexercise}{An uncommon disease}
You are diagnosed with an uncommon disease. You know that there is only
a $1\%$ chance of getting it. Let
\[
  D=\{\text{you have the disease}\},\qquad
  T=\{\text{the test is positive}\}.
\]
It is known that the test is imperfect, since
\[
  P(T\mid D)=0.98,\qquad P(T^c\mid D^c)=0.95.
\]

\textbf{Question A.} Given that you test positive, what is the
probability that you have the disease?

\textbf{Question B.} You take the test again, independently of the
first test conditional on whether you have the disease, and it is
positive again. Given both positive results, what is the probability
that you have the disease?
\end{framedexercise}

\solutionheading{Solution to A.}
We seek $P(D\mid T)$. The prior probabilities are $P(D)=0.01$ and
$P(D^c)=0.99$.
\begin{enumerate}[label=\textbf{Step \arabic*:},leftmargin=*]
  \item \textbf{Find the false-positive rate.} By the complement rule,
  \[
    P(T\mid D^c)=1-P(T^c\mid D^c)=1-0.95=0.05.
  \]
  \item \textbf{Find the probability of a positive result.} By the law
  of total probability,
  \begin{align*}
    P(T)
      &=P(T\mid D)P(D)+P(T\mid D^c)P(D^c)\\
      &=0.98\cdot0.01+0.05\cdot0.99\\
      &=0.0593.
  \end{align*}
  \item \textbf{Apply Bayes' theorem.}
  \[
    \boxed{P(D\mid T)
      =\frac{P(T\mid D)P(D)}{P(T)}
      =\frac{0.0098}{0.0593}
      \approx 16.53\%.}
  \]
\end{enumerate}
The positive test raises the probability of disease from $1\%$ to about
$16.53\%$ under the stated assumptions.

\Needspace{20\baselineskip}
\solutionheading{Solution to B.}
Let
\[
  \begin{aligned}
    T_1&=\{\text{the first test is positive}\},\\
    T_2&=\{\text{the second test is positive}\}.
  \end{aligned}
\]
We seek $P(D\mid T_1\cap T_2)$.
\begin{enumerate}[label=\textbf{Step \arabic*:},leftmargin=*]
  \item \textbf{Find the likelihood of two positive results.} Conditional
  independence gives
  \[
    P(T_1\cap T_2\mid D)=0.98^2=0.9604,
    \qquad
    P(T_1\cap T_2\mid D^c)=0.05^2=0.0025.
  \]
  \item \textbf{Find the probability of two positive results.} By the
  law of total probability,
  \begin{align*}
    P(T_1\cap T_2)
      &=P(T_1\cap T_2\mid D)P(D)
        +P(T_1\cap T_2\mid D^c)P(D^c)\\
      &=0.9604\cdot0.01+0.0025\cdot0.99\\
      &=0.012079.
  \end{align*}
  \item \textbf{Apply Bayes' theorem.}
  \[
    \boxed{P(D\mid T_1\cap T_2)
      =\frac{0.9604\cdot0.01}{0.012079}
      \approx 79.51\%.}
  \]
\end{enumerate}
The second positive result raises the probability from about $16.53\%$
to about $79.51\%$ under the conditional independence assumption.
\chapter{Random variable exercises}

\begin{tcolorbox}[colback=white,colframe=black!45,boxrule=0.5pt,arc=2mm]
\textbf{Exercise 4.1 --- Two throws of a die}\par\smallskip
\textit{Source: Dekking et al., A Modern Introduction to Probability
and Statistics, Section 4.6, p. 51.}

Throw a fair die twice, independently. Let $Z$ count the number of
times a $6$ appears. For an outcome $\omega=(\omega_1,\omega_2)$,
define
\[
  S(\omega_1,\omega_2)=\omega_1+\omega_2,
  \qquad M(\omega_1,\omega_2)=\max\{\omega_1,\omega_2\}.
\]
\begin{enumerate}[label=(\alph*)]
  \item Describe the distribution of $Z$ by giving either its PMF
    $p_Z$ or its CDF $F_Z$. Identify the distribution family and its
    parameters.
  \item List the outcomes in $\{M=2,Z=0\}$, $\{S=5,Z=1\}$, and
    $\{S=8,Z=1\}$, and calculate their probabilities.
  \item Determine whether $\{M=2\}$ and $\{Z=0\}$ are independent.
\end{enumerate}
\end{tcolorbox}

\solutionheading{Part (a): the PMF of $Z$}
Since $Z$ counts the number of sixes in two throws, $Z$ takes values
in $\{0,1,2\}$. Formally, it is the random variable
\[
  Z:\{1,\ldots,6\}^2\longrightarrow\mathbb R,
  \qquad
  Z(\omega_1,\omega_2)
  =\mathbf 1_{\{\omega_1=6\}}+\mathbf 1_{\{\omega_2=6\}}.
\]
Here each indicator is $1$ if the corresponding throw is $6$, and
$0$ otherwise.

To calculate the PMF, we proceed in two steps.
\begin{enumerate}
  \item \textbf{First, show that $Z$ is discrete.}
    Choose the finite set $\mathcal X=\{0,1,2\}$. Every outcome
    produces one of these values, so
    \[
      P(Z\in\mathcal X)=P(\Omega)=1.
    \]
    Therefore, $Z$ is discrete.
  \item \textbf{Next, calculate its PMF.}
    By definition, $p_Z(x)=P(Z=x)$ for $x\in\mathbb R$.
    There are $36$ equally likely ordered outcomes.

    If $x=0$, neither throw is $6$: each throw has $5$ possible values.
    \[
      P(Z=0)=\frac{5\cdot5}{36}=\frac{25}{36}.
    \]
    If $x=1$, exactly one throw is $6$: it can be the first or the second.
    \[
      P(Z=1)=\frac{1\cdot5+5\cdot1}{36}=\frac{10}{36}.
    \]
    If $x=2$, both throws are $6$: the only outcome is $(6,6)$.
    \[
      P(Z=2)=\frac{1}{36}.
    \]
    Hence its probability mass function (PMF) is:
    \[
      p_Z(x)=
      \begin{cases}
        25/36, & x=0,\\
        10/36, & x=1,\\
        1/36, & x=2,\\
        0, & \text{otherwise}.
      \end{cases}
    \]
\end{enumerate}

\solutionheading{Part (a): calculating the CDF}
Alternatively, we can use the cumulative distribution function,
\[
  F_Z(x):=P(Z\leq x).
\]
Here $\{Z\leq x\}=\{\omega\in\Omega:Z(\omega)\leq x\}$:
we collect the outcomes for which the number of sixes is at most $x$.

Since $Z$ takes only the values $0,1,2$, the included values change
only when $x$ reaches one of these numbers. We therefore distinguish
$x<0$, $0\leq x<1$, $1\leq x<2$, and $x\geq2$.

For $x<0$, no possible value of $Z$ is included, so
\[
  F_Z(x)=P(Z\leq x)=P(\varnothing)=0.
\]

For $0\leq x<1$, only $Z=0$ is included:
\[
  F_Z(x)=P(Z\leq x)=P(Z=0)=\frac{25}{36}.
\]
In particular, $F_Z(0)=25/36$.

For $1\leq x<2$, the included values are $Z=0$ and $Z=1$:
\[
  \{Z\leq x\}=\{Z=0\}\cup\{Z=1\}.
\]
These events are disjoint: $Z$ cannot equal both $0$ and $1$ in the
same outcome. By additivity of probability for disjoint events,
\[
  F_Z(x)=P(Z\leq x)=P(Z=0)+P(Z=1)
  =\frac{25}{36}+\frac{10}{36}=\frac{35}{36}.
\]
In particular, $F_Z(1)=35/36$.

\Needspace{10\baselineskip}
For $x\geq2$, all three possible values are included:
\[
  \{Z\leq x\}=\{Z=0\}\cup\{Z=1\}\cup\{Z=2\}=\Omega.
\]
These three events are pairwise disjoint. Therefore,
\[
  \begin{aligned}
    F_Z(x)=P(Z\leq x)
      &=P(Z=0)+P(Z=1)+P(Z=2)\\
      &=\frac{25}{36}+\frac{10}{36}+\frac{1}{36}
        =\frac{36}{36}=1,\qquad x\geq2.
  \end{aligned}
\]
Putting the cases together, its CDF is:
\[
  F_Z(x)=
  \begin{cases}
    0, & x<0,\\
    25/36, & 0\leq x<1,\\
    35/36, & 1\leq x<2,\\
    1, & x\geq2.
  \end{cases}
\]

\solutionheading{Part (b): outcomes and probabilities}
Both conditions in each event must hold for the same ordered pair.
Each of the $36$ ordered outcomes has probability $1/36$.
\begin{enumerate}
  \item \textbf{$\{M=2,Z=0\}$.}
    If the maximum is $2$, both throws are at most $2$ and at least
    one is $2$. All these outcomes also give $Z=0$:
    \[
      \{M=2,Z=0\}=\{(1,2),(2,1),(2,2)\}.
    \]
    Therefore,
    \[
      P(M=2,Z=0)=\frac3{36}=\frac1{12}.
    \]
  \item \textbf{$\{S=5,Z=1\}$.}
    Exactly one throw must be $6$. The other is at least $1$, so
    the sum is at least $7$ and cannot be $5$:
    \[
      \{S=5,Z=1\}=\varnothing,
      \qquad P(S=5,Z=1)=0.
    \]
  \item \textbf{$\{S=8,Z=1\}$.}
    One throw is $6$ and the other must be $2$:
    \[
      \{S=8,Z=1\}=\{(6,2),(2,6)\}.
    \]
    Therefore,
    \[
      P(S=8,Z=1)=\frac2{36}=\frac1{18}.
    \]
\end{enumerate}

\Needspace{20\baselineskip}
\solutionheading{Part (c): independence}
Let $A=\{M=2\}$ and $B=\{Z=0\}$. By the
\hyperref[def:independent-events]{definition of independence},
we must check whether $P(A\cap B)=P(A)P(B)$.

If $M=2$, neither throw can be $6$, so $Z=0$. Thus $A\subseteq B$
and $A\cap B=A$. Using the counts above,
\[
  P(A\cap B)=P(A)=\frac3{36}=\frac1{12}.
\]
On the other hand,
\[
  P(A)P(B)=\frac3{36}\cdot\frac{25}{36}
  =\frac{25}{432}\neq\frac1{12}.
\]
Therefore, $\{M=2\}$ and $\{Z=0\}$ are \textbf{not independent}.
Equivalently, knowing that $M=2$ guarantees that $Z=0$:
\[
  P(Z=0\mid M=2)=1\neq\frac{25}{36}=P(Z=0).
\]
