# Image sources

`sapienza.png` è il logo Sapienza estratto, senza ridisegno, dall'immagine
incorporata nella prima pagina del PDF di Computational Complexity di
Simone Bianco (Exyss), datato 17 febbraio 2025. Trasparenza preservata.

SHA-256 del PDF: `e9286057bfd15366193ebc79d2dcae0fdd62731d2c027993008910af012ccf23`.
Fonte pubblica: https://github.com/Exyss/university-notes

Il logo identifica Sapienza Università di Roma; non è una creazione del
nostro template. Per rimuovere il logo dalla copertina usare `\noteslogo{}`.

`random-variable-map.png` è un'immagine delle slide di Pierpaolo Brutti,
Topic 04a, Fundamentals of Statistical Learning (Part I), Sapienza.
Rappresenta una variabile aleatoria come mappa da $\Omega$ a $\mathbb R$.
